# 设计

- 协议限制：本机 Codex 0.160.0 app-server UserInput 实际 schema 只有文本/图像等输入，无视频类型。采用 HTML video 解码，每段 5 个均匀时间点（0 到结尾前 0.1 秒）合成 JPEG；不转录音频。
- 每轮最多 500 个顶层元素；所有元素元数据入请求。图片预览最多 24 张拼一张，视频最多 4 段各一张，总计最多 5 张；显式超限参考拒绝发送，非显式遗漏与读取失败报告范围。长文本每元素最多 2000 字，总文字预算 60000，标记截断。
- 引用 URL 保存到会话，下轮没有新引用时复用并重新采样；缓存丢失时明确失败，不声称看到了失效引用。采样拼板随消息保存及备份，旧快照只保留历史范围文本，不混作当前画布。
- 计划只允许真实元素 ID 和受限操作参数，无代码/文件路径/任意 URL。普通图片、视频、几何/文字可编辑；组合、框架、生成卡片、音频卡片、任务占位及锁定元素只读。只读元素仍提供元数据。
- 请求前保存快照，执行前持久化 started；每个计划校验当前画板和整个 children 的 SHA256。先在副本准备全部修改，参数/目标不符不发任何变换；成功使用一个 Plait history batch。恢复 started 标记 error，禁止自动重放。
- 删除/替换必须 UI 确认；其他操作仅用户指令具有编辑意图时自动执行，咨询性提示转为确认。模型返回计划与宿主实际结果分别呈现，不将模型答复当执行证明。
- 运行时既有生成计划与新 canvasPlan 合并保存，二者生命周期独立；修改已有作品不触发生成队列。

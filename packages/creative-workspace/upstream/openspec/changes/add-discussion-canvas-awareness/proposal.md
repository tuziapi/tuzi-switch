# 讨论参考视频与画布控制（UC-DISCUSS-CANVAS-02）

## Why
画布输入已经携带参考视频，但讨论请求只转发图片，Codex 因而看不到视频。讨论也没有整张画布快照和已有元素编辑执行器。

## What Changes
- 保留 Codex，用本地视频采样拼板及时间码传递画面，明确时长、范围、数量与不含声音的限制。
- 每轮捕获当前画板元素、文字、位置和有界媒体预览，包含未选中元素。长文本截断及媒体遗漏必须可见。
- 对明确指令执行可撤销的定位、移动、排列、缩放、复制、文字编辑；删除和同类型媒体替换总要先确认。
- 保存参考范围与计划生命周期；按画板及快照摘要校验，重启不重放已开始操作。

## Approval
用户已在本会话选定“保留 Codex，自动传视频关键帧＋时间码，并明确显示抽帧范围”和“按明确指令直接执行可撤销编辑；删除、替换先确认”。实现使用均匀采样，不宣称语义关键帧检测或完整视频理解。当前范围为本地实现/验证/提交，不包括安装覆盖、push 或正式发布。

## Impact
讨论请求、会话恢复/备份、画布 Plait 变换、确认 UI、Rust Codex 输出 schema。旧消息字段可缺省；新增字段有恢复校验。模型 Key 和执行模型选择不变。

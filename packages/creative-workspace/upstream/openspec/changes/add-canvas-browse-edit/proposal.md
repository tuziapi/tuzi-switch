# Change: 桌面画布默认选择与平移修复

用户于 2026-11-08 选择方案 B：默认浏览，顶部明确区分“浏览／编辑”，记住上次模式。随后用户明确要求移除顶部额外按钮，只保留平移改善；此反馈覆盖顶部按钮要求。仅本地修改、验证及构建。

最新反馈明确要求默认工具为“选择”，覆盖默认浏览和模式记忆要求。每次进入使用选择，保留滚轮和 Space 临时平移。

## Why
选择模式下拖动图片用于移动元素；用户要求默认选择，并可通过滚动、手形工具或 Space 临时拖动平移画布，避免额外模式按钮。

## What Changes
- 桌面集成每次进入使用选择工具，实际画布指针和工具栏保持一致。
- 不增加顶部浏览/编辑按钮；使用已有左侧手形/选择工具及 H/V 快捷键，保留 Space 临时平移。
- 复用原有平移与选择，不增加逐帧计算或惯性动画；不改模型或画板内容格式。
- 不再读写 `tuzi-canvas-interaction-mode-v1`；旧值保留但不影响初始工具，无需数据迁移。

## Impact
Drawnix 初始工具和临时平移支持。需要验证默认选择、手形/滚轮/Space 平移、图片移动、快捷键/输入隔离及重启。不改变非集成上游的默认行为，不新增网络调用。

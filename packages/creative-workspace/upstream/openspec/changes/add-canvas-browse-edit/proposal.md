# Change: 桌面画布明确浏览与编辑

用户于 2026-11-08 选择方案 B：默认浏览，顶部明确区分“浏览／编辑”，记住上次模式。该选择为本提案实施授权，仅本地修改、验证及构建。

## Why
选择模式下拖动图片会移动元素，用户希望平移画布时容易误操作。已有手形工具可正确平移，但入口及默认行为不符合浏览优先的使用方式。

## What Changes
- 桌面集成首次进入使用手形浏览；后续恢复本机浏览/编辑选择。
- 顶部可访问的浏览/编辑按钮与现有工具、H/V 快捷键同步；其他绘制工具归入编辑。
- 复用原有平移与选择，不增加逐帧计算或惯性动画；不改模型或画板内容格式。
- 新增本地偏好 `tuzi-canvas-interaction-mode-v1`，仅接受 browse/edit，缺失或损坏回退 browse，存储不可用不阻塞操作。

## Impact
宿主创作工具栏、Drawnix 初始工具、局部模式控制和本地偏好。需要验证图片区域拖动、编辑移动、快捷键/输入隔离、窄窗口和重启恢复。不改变非集成上游的默认行为，不新增网络调用。

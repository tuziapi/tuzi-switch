# Change: 完成已授权的指令生成与媒体交付

用户已要求工具优先、界面辅助，生成结果回到画布和当前对话，并在验收后发布测试版。本提案记录该已批准范围的落地；不新增第三方托管或修改账户授权。

## Why
连接器遗漏视频参数、无法找回未知编号的任务，且只返回内部媒体 URL，造成需要手动操作和无法直接交付结果。

## What Changes
- 公布模型可用的视频参数；严格校验时长、尺寸、比例，禁止静默替换。
- 提供有界任务列表、等待和显式结果导出；复用已有任务，不自动重试付费生成。
- 本机结果导出到应用管理目录，返回绝对路径与有界图片预览；补充工具使用顺序及教程。

## Impact
仅本地 MCP 契约、创作桥、原生媒体导出和教程；无服务端或数据库字段迁移。正式发布和外部服务选型不在本修复范围。测试发布仍受已有验收门禁约束。

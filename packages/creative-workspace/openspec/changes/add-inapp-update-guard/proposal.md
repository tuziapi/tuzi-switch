# 应用内更新与创作保存保护

2026-11-04 用户已明确批准“应用内下载，完成后点击重启安装”，同时要求下载页同步正确版本。

## Scope
应用内统一下载进度、签名校验、显式重启安装；安装前等待任务恢复完成、阻止活跃生成、刷新未保存画布并检查原生请求。下载页保留直接安装文件及首次升级步骤。不会因下载完成自动退出应用。

## Impact
宿主 UpdateContext、Tauri updater、创作持久化、签名发布流水线。账户契约及模型请求协议不变；无新数据库字段。现有 v1.5.0/1.5.1 需手动安装一次新机制版本。Windows/Linux 实际桌面升级验收单独记录。

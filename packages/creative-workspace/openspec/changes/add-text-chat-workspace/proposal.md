# UC-TEXT-01 文本聊天工作区

2026-11-08。用户已选择完整聊天区、专注/画布并排，要求覆盖现有 Claude、OpenAI、DeepSeek 等文本模型。该选择批准本方案的本地实施；不包含远程推送、PR、发布或真实付费调用。

## Why
现有抽屉输入主要服务创作生成；普通聊天混入 Agent 提示词，消息操作空缺，共享取消状态且协议解析偏向 Chat Completions。

## What Changes
- 同一抽屉增加文本对话/创作助手切换、专注展开/并排；原创作及历史保留。
- 新文本会话复用现有模型选择、账户/手动请求桥接与聊天存储。按协议适配 OpenAI Chat Completions（含 DeepSeek/Claude 兼容接口）、Responses、Anthropic Messages、Gemini。
- 会话独立请求与停止；部分内容保存、异常状态、复制、显式重试/重新生成、历史搜索、重命名、草稿恢复。
- Markdown/代码/公式阅读；节流渲染和跟随滚动；高级系统提示词与输出长度。
- 新字段可选并有默认语义，旧会话归创作助手，未删除/迁移原数据；协议/能力由配置与端点声明决定，不宣称所有上游型号已真实验证。

## Validation
合成协议分块/错误/取消/结束、会话并发/保存失败/重启、原有回归、类型、构建、浏览器布局与桌面隔离安装实测。代码、合成测试、实际供应商验证、跨平台实机与发布分别记录。

# 2026-06-15 顶部升级弹窗体验人工测试文档

## 测试范围

- 有更新时顶部 `兔子switch` 标题右侧显示升级按钮。
- 点击升级按钮后弹出更新弹窗。
- 点击更新后展示下载进度。
- 原生更新安装完成后显示重启提示。
- 手动 fallback 更新只打开下载页，不提示已安装。

## 人工测试步骤

1. 准备一个低于 GitHub Release 最新版本的本地安装包。
2. 启动应用并等待自动检查更新完成。
3. 确认顶部标题右侧出现升级图标。
4. 点击升级图标，确认弹出更新弹窗并展示当前版本和目标版本。
5. 点击「更新到 vX.Y.Z」。
6. 确认下载期间按钮禁用，并显示下载进度。
7. 下载并安装完成后，确认弹窗变为「更新已安装」状态。
8. 点击「稍后重启」，确认弹窗关闭且应用继续可用。
9. 再次打开更新弹窗，点击「立即重启」，确认应用重启。

## 回归关注

- 关于页「检查更新」入口仍可使用。
- 没有更新时顶部不显示升级按钮。
- 便携版或 updater 不可用时，仍走已有手动下载兜底。

# 兔子助手 v1.5.7

本版改进 opentu 桌面工作区的批量生图布局和交互，并完善正式渠道的更新检查。

## 2026-11-06 修复重建

- 修复部分图片能预览但右键复制、另存为、定位文件失败的问题，同时修复内联图片缓存和大参考图读取。
- 恢复外部图片拖入画布的桌面配置。
- 修复启动后直接重命名项目可能清空画布的问题，并保护未打开项目的排序、移动与复制内容。
- 本机已安装隔离修复包，完成菜单、用户手动拖图、20 张合成生成与退出后重命名恢复验证。Windows/Linux 实机及高分辨率真实生成仍未完成本轮验收。
- 保持 v1.5.7，同版本用户需手动下载安装修复包。原版本标签保留，修复包的实际源码见 BUILD-INFO.json 和平台 manifest。

## 批量生图

- 批量任务按每行 3 张排列，在准备阶段提前显示整批占位。
- 结果回到各自固定位置，完成时不再自动抢走视口，保留当前缩放。
- 减少无关任务事件和进度变化引起的重复刷新，整理批量准备与位置预留逻辑。

## 更新与安装

- 从 tuziapi/tuzi-switch 正式仓库检测新版，先展示更新说明。
- 本版为未签名手动安装发行：下载对应系统的完整安装包后手动安装。没有自动更新签名清单，不支持本版安装包的应用内验签安装。
- 保留未来正式签名发行的下载、严格验签、保存保护和显式安装重启实现；本次未完成正式密钥配对及真实升级验收。

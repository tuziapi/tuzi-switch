# 兔子助手 v1.6.5

这次更新完善电商创作流程，并统一账户、创作和网站入口。

- 电商生图按作品方向组织生成计划，可以分别选择主图、场景、细节等方向及数量，逐张生成、保存和查看结果。
- 模型参数与画布配置保持一致；商品原图、风格参考图和爆款复刻参考用途分明，平台、地区和语言建议参与生成要求。
- 创作配置侧栏支持拖动调整、收起及双击恢复；任务保存模型参数快照，重新打开时保留原始选择。
- 兔子账户采用全宽页面，通过顶部导航切换创作、直连站和兔小店；点击“兔子助手”返回工具配置首页并保留工具及侧栏偏好。
- 网站在助手内独立浏览，打开导航或弹窗时正确避让；保留各自浏览状态，并限制远程页面访问本地命令。
- 同步网页 OpenTu 已选的画布编辑、选择、渐变、持久化和按需加载改进，补充 Vidu/Mix 与 MJ V8.2 参数适配。

模型可用性与费用由配置的服务决定，生成结果需核对商品外观、文字及规格。平台建议不等于审核保证；本版不提供自动拼接详情长图、整套视觉一致性保证或尚未接通的视频增强。官方 MCP 自动授权仍取决于服务端能力。

正式版沿用原应用身份、用户数据和更新公钥；1.6.2 及更新正式版可使用应用内签名更新，1.6.1 及更早版本需手动安装。独立测试版的数据不会自动合并至正式版。macOS 安装包使用 ad-hoc 签名、未公证，Windows 沿用无发行商代码签名的分发方式；更新包使用正式渠道签名。

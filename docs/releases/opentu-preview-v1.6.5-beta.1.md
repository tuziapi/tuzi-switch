# OpenTu 1.6.5-beta.1 集成测试版

本次更新集中优化电商创作，并同步网页 OpenTu 的已选功能及助手内的网站入口。

- 电商生成计划支持按创作方向组织多张图片，明确展示数量、进度与结果；快捷优化项、平台要求及模型参数参与实际任务配置。
- 商品原图、风格参考与爆款复刻参考各自有明确用途；任务保存模型参数快照，恢复时保留原始选择。
- 创作设置侧栏支持拖动调整宽度与双击恢复，继续使用已确认的配色和图片展示样式。
- 同步网页画布编辑、选择、渐变、持久化及按需加载改进；补充 Vidu/Mix 参数适配与 MJ V8.2。模型可用性仍取决于用户配置的服务。
- 整合网站入口、原生网页切换和菜单遮挡处理，保留各自浏览状态；强化远程页面与本地命令的隔离。
- 完整包包含本地视频压缩引擎与 Claude 运行时，修复测试包启动协议及图片拖放配置。

## 安装说明

这是独立安装、独立数据目录的测试版，不覆盖正式版，不自动迁移正式版账户或项目，不提供自动更新。已有 OpenTu 验收版用户可手动更新；建议先导出重要项目。

提供 macOS Apple Silicon、macOS Intel、Windows x64、Linux x64 与 Linux ARM64 安装包。Mac 为 ad-hoc 签名、未公证；Windows 无发行商代码签名，系统可能显示来源提示。

## 验证范围

本机 Mac ARM 已完成完整桌面构建、网站切换、双图/参数恢复、侧栏拖动、本地视频压缩导出、冷启动及画布连接器读取。自动化和各平台打包结果以同版构建清单为准。

本轮没有新增付费模型请求，不承诺所有模型生成效果；新候选的真实网站登录、跨平台用户实机及正式版升级仍需验收。视频生成验收仅使用用户指定的 MiniMax-H3，未使用 doubao-seedance-2-5-260628。本版本供测试反馈，不代表正式上线验收全部完成。

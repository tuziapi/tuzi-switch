# 兔子助手 v1.5.1

修复 opentu 生成图片在桌面画布中不显示、进度渲染异常，以及添加 Codex 供应商时可能出现的数据库外键错误。

## 本次更新

- 图片右键支持复制图片、另存为、显示图片文件、预览原图及复制提示词。定位文件时自动保存原图副本；重复定位复用同一份文件，保留用户修改过的副本。
- 单张图片导出使用系统保存对话框，取消保存不再显示成功；原图导出保留原始文件内容。
- 同步批量选中行导入、Excel 图片往返、已完成结果回填画布、GPT 蒙版编辑、图片缩放/拆图、工具栏偏好、任务历史筛选、模型目录及 Suno 参数/结果支持。
- 改善画布加载、结果恢复与跨页保存，保留统一账户关联和手动配置。

## 下载与更新

公网下载页：https://aiw520.github.io/tuzi-switch/

macOS 提供 Apple Silicon / Intel DMG；Windows 提供 EXE / MSI；Linux 提供 DEB / RPM / AppImage。下载页面直接获取安装文件，无需下载 Actions 压缩包。

来自本仓库的 v1.5.0 正式客户端已支持自动检查新版本：启动、每 6 小时及恢复联网/回到前台时检查（唤醒检查有 15 分钟间隔），也可从设置手动检查。点击更新提醒会打开对应系统的安装包下载；下载后请退出旧客户端并手动安装。不会静默覆盖安装或自动重启。

使用原正式应用身份和数据目录。独立集成测试应用的数据不会自动迁入。安装前先完成正在生成的任务并备份重要作品。

## 验证与已知限制

本次 macOS 原生客户端已实际验证图片导入、右键、原图预览、系统另存为及取消、Finder 定位、剪贴板跨应用粘贴、正常重启后图片恢复和供应商保存；另存为/定位副本与原图逐字节一致。生成画布修复通过双浏览器合成接口回归；真实账户付费生成完整链尚未完成验收，不能将合成测试当作真实服务验收。

安装包尚无开发者签名/Apple 公证。Windows/Linux 实际安装升级、完整旧媒体迁移、跨存储回滚、扩展隔离、运行中任务退出保护，以及批量和音视频原生导出仍有未完成验证项。

Release 附有各平台构建 manifest、SHA256SUMS 和对应源码；客户端与集成模块许可证见源码记录。

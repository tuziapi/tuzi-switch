# 兔子助手 v1.5.2

新增应用内下载更新。下载并校验完成后，点击“重启并更新”安装，无需跳到浏览器。

- 设置页、顶部入口和全局提醒共享下载进度，关闭弹窗后可以继续下载。
- 支持下载失败重试、签名校验、稍后安装；下载结束不会自动中断工作。
- 安装前检查生成任务、画布保存和原生请求，未完成时保留下载并提示稍后重试。
- 下载页面显示实际安装包版本，补充 macOS 安装步骤，并在回到页面时刷新版本信息。
- 保留 v1.5.1 的画布渲染修复、供应商保存、图片右键和 OpenTu 新特性。

## 首次升级

v1.5.0/v1.5.1 用户需要手动安装一次 v1.5.2，后续版本即可应用内更新。macOS 请退出旧版，把新 DMG 中的“兔子助手”拖入“应用程序”并替换，再从“应用程序”打开。仅下载或打开 DMG 不会替换正在运行的旧应用。

下载页：https://aiw520.github.io/tuzi-switch/

macOS 提供双架构 DMG，Windows 提供 EXE/MSI，Linux 提供 DEB/RPM/AppImage。系统权限确认仍可能出现；应用更新签名不等于 Apple 公证或 Windows 开发者签名。

## 验证与限制

更新状态机、签名/篡改、创作任务与保存阻塞已有自动化和浏览器回归。跨平台真实安装升级与旧媒体完整迁移仍需继续验收；真实账户付费生图链仍未完成验收。安装前请保存重要作品。应用内更新包、签名和源码随 Release 发布。

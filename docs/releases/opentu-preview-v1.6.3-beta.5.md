# OpenTu 1.6.3-beta.5 测试版

Claude Desktop 恢复两种可切换的配置入口：普通配置保留原供应商列表，模拟客户端模式恢复线路选择、模型管理和启动向导。切换会记住选择，不更改已有线路。

Windows、macOS 和 Linux 向导采用免本地根证书流程：检测已安装的 Claude Desktop，检查并应用线路，需要时自动启动本地路由，然后打开官方客户端。请先完全退出 Claude 再操作；检测、配置或启动失败会明确显示错误。

可选功能区域保留说明。旧注入式语音、电脑控制和 Cowork 开关不会恢复；Claude 自身功能是否可用需在其客户端确认。旧兼容会话恢复和证书清理仍可从高级设置进入。

本版是独立 OpenTu Preview 测试包，使用手动安装，不启用自动更新，不替换正式发行通道。构建及自动化检查不代表各平台真实账号、Claude 对话和客户安装升级已全部验收；完成对应平台验收后再用于客户正式交付。WorkBuddy 登录和账号切换继续在原客户端操作。

下载后可使用附件 SHA256SUMS 核对文件完整性。

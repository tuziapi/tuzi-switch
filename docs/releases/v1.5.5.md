# 兔子助手 v1.5.5

将包含 opentu、账户四页工作区、图片/视频/音乐适配的统一客户端接入正式仓库 `tuziapi/tuzi-switch` 的发布渠道。

- 下载页面、七种安装文件和版本信息统一到正式仓库，测试仓库仍独立保留。
- 本次按用户确认交付未签名的手动安装包，不提供 `latest.json` 自动更新清单或更新签名；请从正式下载页下载后安装。
- 客户端内置更新地址和原有公钥仍属于正式渠道；不更换为测试密钥，也不关闭运行时验签。
- 正式统一客户端只使用完整安装包更新，避免旧界面热更新缓存覆盖内置创作工作区；保留原用户数据和缓存文件。
- 四平台从正式源码重新构建，核对版本、源码提交、构建执行来源和七个安装文件的 SHA256；旧测试包不重命名复用。

# 兔子助手 v1.5.5

将包含 opentu、账户四页工作区、图片/视频/音乐适配的统一客户端接入正式仓库 `tuziapi/tuzi-switch` 的发布渠道。

- 下载页面、七种安装文件、版本信息和应用内更新指向正式仓库，测试仓库仍独立保留。
- 使用正式渠道原有更新公钥验证签名；缺少对应私钥或签名不匹配时构建失败，不退回测试密钥或无签名更新。
- 正式统一客户端只使用完整安装包更新，避免旧界面热更新缓存覆盖内置创作工作区；保留原用户数据和缓存文件。
- 版本身份、四平台来源、七个安装文件摘要和更新签名通过检查后才允许发布，旧发布流水线已停用。

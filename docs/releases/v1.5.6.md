# 兔子助手 v1.5.6

- 接入 gpt-image-2.6-1k、gpt-image-2.6-flare、gpt-image-2.6-sunburst 的基础图片生成与编辑，支持已验证线路的提示词 GIF 请求及 GIF 原始文件保存。
- 更新后自动获取已启用供应商的授权模型列表；兔子账户连接后自动同步，保留手动配置、已取消选择的模型及现有绑定。网络失败会有限重试，不触发生图或费用。
- 优化批量生成中的画布拖动和输入：局部刷新进度、复用任务快照、减少无变化渲染与保存，保留批量数量和现有并发。
- 延续 opentu 图标、精简项目页、生成错误详情及正式版本更新提醒。

正式安装文件：https://github.com/tuziapi/tuzi-switch/releases/tag/v1.5.6

正式下载页：https://tuziapi.github.io/tuzi-switch/

本版提供 macOS Apple Silicon / Intel、Windows EXE / MSI、Linux DEB / RPM / AppImage。当前为未签名手动安装交付：无 Apple 公证、Windows 开发者签名或自动安装更新清单。应用可提示新版并打开正式下载，安装后保留原有配置与作品。

模型能力按账户和线路授权；本次为基础接入，不包含官方组专属的 SVG/GIF 高级参数。已有供应商才能自动获取模型，未配置来源的用户仍需先完成账户或供应商配置。合成回归与构建验证不代替全部供应商、跨平台实机及旧数据迁移验收。

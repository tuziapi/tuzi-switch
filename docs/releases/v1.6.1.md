# 兔子助手 v1.6.1

修复手动更新入口容易停在“打开更新下载失败”的问题，保留 1.6.0 的创作讨论、画布和多媒体功能。

- 检查更新后固定已校验的版本和平台下载地址。点击“下载安装包”直接交给系统浏览器，不再因第二次 GitHub 查询失败或出现更新版本而阻断下载入口。
- 增加打开中的状态和重复点击保护；系统打不开浏览器时，在弹窗内保留错误信息，提供复制安装包链接、打开对应版本下载页及手动复制入口。
- Windows 在独立、已初始化 COM 的线程调用系统浏览器，避免直接使用未初始化的异步工作线程；不修改默认浏览器或系统协议设置。

当前仍采用完整安装包手动更新，没有签名自动安装。本次不关闭验签、不替换更新公钥；已声明签名的版本继续使用原生签名更新流程。

旧版内部按钮无法通过网页修复。遇到错误的 1.5.7/1.6.0 用户，请先从正式下载页下载安装本次修复版。原账户及项目数据路径不变，安装前保存创作并退出旧版。

macOS 包未经 Apple 开发者签名或公证。Windows 构建机和模拟回归不代替每台用户设备的验收；1.6.0 中备份跨存储回滚、自定义工具导入及音频/Codex 完整真实流程等既有验收限制继续保留。

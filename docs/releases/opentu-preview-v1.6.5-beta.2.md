# OpenTu 1.6.5-beta.2 集成测试版

本次更新让账户与助手导航更清楚，保留 beta.1 的电商创作、画布与内嵌网站功能。

- 兔子账户改为全宽页面，与创作、直连站、兔小店统一使用顶部导航。
- 点击“兔子助手”返回工具配置首页，保留此前选中的工具和侧栏展开状态。
- 电商创作支持按方向生成多张图片、区分商品与参考图、应用模型参数和平台建议，配置侧栏可拖动调整。
- 保留网页 OpenTu 已同步的画布编辑、持久化和按需加载改进，以及独立网站浏览状态。

这是独立安装、独立数据目录的测试版，不自动迁移正式版数据，不提供自动更新。已有测试版可手动更新，重要项目建议先导出。提供 macOS ARM64/Intel、Windows x64、Linux x64/ARM64 安装包；Mac 使用 ad-hoc 签名且未公证，Windows 无发行商代码签名。

账户与助手入口已在本机完整桌面包实际点击验证，自动化与各平台安装检查以同版构建报告为准。模型可用性取决于配置服务，不承诺所有模型或画质；未接通的视频增强及官方 MCP 服务端自动注册不在本轮发布范围。正式版需要另行通过签名、安装升级与数据保留验收。

# 兔子助手 v1.6.4

新增电商生图工作区，把商品素材、模型选择、快捷优化和作品记录放在同一页面。商品、穿戴与视频任务分类展示，沿用暖灰配色与手动切换的作品预览。

- 商品套图、A+/详情页支持按模块逐张生成；完成一张即保存一张，可单张重试、导出或插入画布。详情页模板是结构示意，本版不提供自动拼接长图或整套 ZIP 导出。
- 商品原图和风格参考图可从预览区或设置区添加，共享最多三张素材。平台、地区、语言、比例及快捷优化集中设置，生成前显示张数和计划。
- 模型选择复用创作配置。提示词、快捷项、模型及供应商引用、视频参数在本机保留；原配置暂不可用时阻止新请求，避免误用其他供应商。未保存到任务的上传素材需重新选择。
- 视频提供商品动态展示、参考视频创意生成和本地压缩。MiniMax-H3 图片首帧的输出比例跟随原图，界面明确提示。尚未接通的视频去背景、4K 超分、变清晰和去水印入口暂不提供，已有历史数据保留。
- OpenTu 本机连接增加三步教程与可复制指令，补齐任务续查、结果保存及画布交付；兔子官方 MCP 提供本机 Codex 连接预检，自动授权仍取决于服务端能力。

AI 生成结果需核对商品外观、文字与规格。请提供真实商品资料；不承诺商品细节逐像素一致、自动生成可靠规格数据或严格复刻参考图/视频。模型可用性及费用由所配置的服务决定。

正式版保留既有应用身份、用户数据与更新公钥。已使用新公钥的版本可通过应用内签名更新；1.6.1 及更早版本仍需手动安装。安装包沿用现有分发方式：macOS 为 ad-hoc 应用签名、未公证；更新包另外使用正式渠道签名。完整验收范围以发布报告为准。

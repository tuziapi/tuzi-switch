# 兔子助手 v1.5.0

一个客户端使用工具管理、兔子账户和 opentu 创作。进入创作时导航自动收起；创作配置支持关联兔子账户、复用已有配置及手动配置。账户四页与 PR #54 的功能一并包含。

## 下载与安装

- Apple Silicon Mac：下载 `tuzi-assistant-macos-arm64.dmg`。
- Intel Mac：下载 `tuzi-assistant-macos-x64.dmg`。
- Windows 64 位：下载 `tuzi-assistant-windows-x64.exe`，也提供 MSI。
- Linux 64 位：按系统选择 DEB、RPM 或 AppImage。

上述附件是直接安装文件，无需下载 Actions ZIP 或登录 GitHub。macOS 打开 DMG 后将兔子助手拖入“应用程序”；Windows 打开 EXE 后按提示安装。安装前退出正在运行的旧客户端，并先完成正在生成的任务。公开下载页：https://aiw520.github.io/tuzi-switch/

新版使用正式应用身份及原助手配置目录，启动后检查本仓库新版本，点击提醒下载当前系统的完整安装包。不会自动覆盖安装或重启。此前 Tuzi Assistant Test 使用独立目录，账户和作品不会自动搬入正式应用；请保留原应用和数据，按需导出备份。

## 已知限制

安装包未配置开发者签名或 Apple 公证，操作系统可能提示无法验证发布者。完整旧 opentu 媒体迁移、跨存储导入失败回滚、自定义扩展隔离、运行中任务退出保护、真实供应商全业务、三平台安装升级回退仍有未完成的验收项。请保留数据备份，避免在任务运行时退出；发布状态不代表上述验收全部通过。

每个平台包含构建 manifest；SHA256SUMS 可核验安装包，源码随 Release 提供。客户端 MIT，创作工作区及下载页第三方许可证见源码中的 LICENSE 和 SOURCE 记录。

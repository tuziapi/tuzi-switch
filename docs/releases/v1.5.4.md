# 兔子助手 v1.5.4

补齐 opentu 现有视频、音乐功能的兔子账户适配，修复原生画布媒体显示和任务状态。

- 账户来源支持 MiniMax-H3、Seedance、Kling 和 Suno 既有接口，通过 75 项固定动作映射执行；保留手动配置与模型 Key 权限校验。
- 修复 macOS 视频计时正常但画面空白的问题，音视频媒体层随画布移动、缩放同步。
- 修复音频标题遮挡播放按钮，任务卡片空白、生成阶段退回“提交中”和取消状态误显示的问题。
- 图片未就绪时仅显示“正在加载图片”，后台结果与画布同步。
- 修复模型列表后台刷新导致已勾选模型丢失、确认后“添加 0 个”的问题。

## 验证范围

宿主 760 项、创作 1861 项、原生创作 12 项（包含 75 路由本机 HTTP）通过；Chrome/WebKit 的生成成功、失败、取消及刷新不重发检查通过。macOS 隔离原生包使用合成项目验证了视频实际画面、音频播放、缩放同步、正常退出重启后的保存恢复和再次播放。

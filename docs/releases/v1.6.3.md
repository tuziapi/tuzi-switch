# 兔子助手 v1.6.3

- Claude 配置保留普通配置与模拟客户端向导两种模式；向导支持模型选择、功能选择和启动官方 Claude，准备环境无需安装本地根证书。
- 修复 GPT/Codex 模型被客户端过滤的问题，模型菜单展示真实名称，并修复隔离验收版配置与启动目录不一致。
- 集成 WorkBuddy 配置与客户端登录入口，补齐未安装 Claude 时的官网下载提示和 Windows 环境准备修复。
- 同步 OpenTu 画布生成、继续编辑、视频上下文及 MCP 协作改进。

1.6.2 用户可通过应用内签名更新升级；1.6.1 及更早版本请先手动安装新版本。独立 OpenTu 验收版与正式版的数据目录不同，不自动合并验收数据。

支持包：macOS Apple Silicon / Intel、Windows x64（EXE / MSI）、Linux x64（DEB / RPM / AppImage）。Linux ARM64 仍保留测试渠道。Claude 功能依赖官方客户端及其平台支持；GPT 兼容路由已在 Mac ARM 的 Code/Cowork 验证，官方客户端升级后仍可能需要适配。Windows 上真实 Claude 会话和 WorkBuddy 真实账号未在本轮完整验收。

更新包使用既有正式更新签名；这不代表 Apple Developer ID / 公证或 Windows Authenticode。对应源码及依赖许可证随发行提供。

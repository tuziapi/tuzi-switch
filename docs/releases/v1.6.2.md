- 适配 `doubao-seedream-5-5-261028` 的生图、透明 PNG、分层和 OCR，修复预览、分层来源传递及完成后占位卡残留。

本文件为正式发布准备的版本说明；实际发布状态以 GitHub Release 为准，验收记录位于 `docs/development/2026-11-16-final-candidate-reprobe.md`。

由于原自动更新私钥没有备份，本版是新正式密钥的手动过渡版：旧版用户需要下载对应安装包，退出应用后手动安装一次。请保留原应用数据目录。后续自动更新使用新公钥；本版不公开旧客户端无法验证的自动更新清单。

自动更新签名用于验证更新包来源与完整性，不等于操作系统开发者证书。macOS 包仍未经 Apple 开发者签名和公证，Windows 包仍无 Authenticode 证书。Mac 可使用下载页的摘要校验安装脚本，或在确认来源后通过系统“隐私与安全性”打开。

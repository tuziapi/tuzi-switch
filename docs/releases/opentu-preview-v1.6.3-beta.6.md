# OpenTu 1.6.3-beta.6 电商创作测试版

电商生图工作区集中提供商品、穿戴和视频任务。新版采用暖灰配色、左侧任务与创作设置、右侧自适应作品预览；分类靠左展示，图片支持手动切换。

- 商品原图与风格参考图可从两个入口上传，共享最多 3 张素材；支持追加与移除。
- 生成模型复用创作配置，可按任务选择；快捷优化项、平台、语言、比例与生成计划集中设置。
- 图片逐张独立生成，完成即显示并保存；可切换生成记录、保存结果、插入画布及重试失败项。
- 视频保留带货视频、参考视频创意生成及本地压缩。移除尚未接通的背景移除、4K 超分、变清晰和去水印入口，已有历史记录保留。
- OpenTu 本机连接增加教程与可复制指令，补齐任务续查和媒体交付；兔子官方 MCP 增加本机 Codex 连接与服务可用性检查。

MiniMax-H3 的参考视频生成属于创意重生成，不承诺商品逐像素一致、精确背景替换或请求时长与分辨率严格一致。AI 图片与视频需逐项核对商品外观、文字和规格后再使用。

官方 MCP 自动授权仍依赖服务端开放；界面会提示实际状态。不同客户端对本机媒体的展示支持不同。本轮未宣称全部模型、客户端和跨平台业务已完成真实账号验收。

本版是独立 OpenTu Preview 测试包，手动安装，无自动更新；不替换正式版通道。macOS 为 ad-hoc 签名、未公证，其余平台无开发者发行签名。请先用测试资料验证工作流。附件 SHA256SUMS 可用于核对完整性，构建清单记录各平台来源与自动化检查。

# 兔子助手 v1.5.3

修复 opentu 创作中的模型获取、生图结果交付和删除确认问题。

- 修复原生客户端大响应到达顺序导致的“请求结果待确认”，模型列表与生成图片可正常接收。
- “获取模型 / 保存并获取模型”点击后立即显示状态，防止重复请求；支持超时退出、错误提示和重试，切换供应商后不再弹出旧结果。
- 兼容兔子账户图片模型的 generate / edit 接口标签，保留 Key 权限、模型归属和请求路径校验。
- 修复历史删除确认弹窗的显示层级与样式。
- 图片加载阶段去掉绿色进度圈和进度条，只显示“正在加载图片”。

## 下载与更新

v1.5.2 用户可在应用内下载新版本，校验完成后点击“重启并更新”。v1.5.0 / v1.5.1 及旧独立测试客户端需手动安装本次版本。

下载页：https://aiw520.github.io/tuzi-switch/

macOS 提供 ARM64 / Intel DMG，Windows 提供 EXE / MSI，Linux 提供 DEB / RPM / AppImage。macOS 请退出旧版，将 DMG 中的兔子助手拖入“应用程序”并替换，再从“应用程序”打开。

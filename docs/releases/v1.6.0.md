# 兔子助手 v1.6.0

本版围绕画布创作，增加与主输入框协同的讨论、批量任务规划和可选的本地 Codex 连接。

## 创作讨论

- 复用创作配置中的文本模型，流式显示回复；模型提供的思考内容单独显示。
- 主输入框上方的窄条可展开讨论，也可打开更大的对话窗口。
- 图片、视频、音频的执行模型与讨论文本模型分别选择；批量计划先预览，确认后执行。
- 图片和视频任务同步显示在画布，完成后放入对应位置；文本结果按需手动放入画布。
- 可选连接已安装并登录的本地 Codex；未连接时使用所选文本模型。

## 配置与画布

- 使用兔子助手品牌图标，精简顶部导航，增加明确的“创作配置”入口。
- 发送前发现缺少配置时打开配置窗口并保留草稿，不自动重复发送。
- 文本聊天支持图片、PDF、文本及代码附件；实际理解能力取决于所选模型。
- 接入 Gemini Omni 视频请求，修复画布视频拖动、错误卡片操作及图片预览。
- 改进模型菜单定位、长会话渲染及画布平移，默认使用选择工具。

## 安装说明

候选构建先在测试仓库验收。正式发布前须完成安装包版本、构建来源、摘要、更新渠道、下载页和脚本的一致性检查。测试仓库与正式仓库使用各自的更新签名，不能相互替代。

第三方模型的可用性、返回格式、计费及思考内容由供应商决定。支持平台的构建通过不等于所有设备均已实机验收。

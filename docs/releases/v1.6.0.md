# 兔子助手 v1.6.0

本版围绕画布创作，增加与主输入框协同的讨论、批量任务规划和可选的本地 Codex 连接。

## 创作讨论

- 复用创作配置中的文本模型，流式显示回复；模型提供的思考内容单独显示。
- 主输入框上方的窄条可展开讨论，也可打开更大的对话窗口。
- 图片、视频、音频的执行模型与讨论文本模型分别选择；批量计划先预览，确认后执行。
- 图片和视频任务同步显示在画布，完成后放入对应位置；文本结果按需手动放入画布。
- 可选连接已安装并登录的本地 Codex；未连接时使用所选文本模型。

## 配置与画布

- 使用兔子助手品牌图标，精简顶部导航，增加明确的“创作配置”入口。
- 发送前发现缺少配置时打开配置窗口并保留草稿，不自动重复发送。
- 文本聊天支持图片、PDF、文本及代码附件；实际理解能力取决于所选模型。
- 接入 Gemini Omni 视频请求，修复画布视频拖动、错误卡片操作及图片预览。
- 改进模型菜单定位、长会话渲染及画布平移，默认使用选择工具。

## 安装说明

本次提供正式渠道手动安装包。请通过正式下载页选择对应系统安装；应用内可发现新版并打开下载安装入口，不提供本次签名自动安装。macOS 包未进行 Apple 开发者签名或公证。

正式源码与内置更新渠道均为 `tuziapi/tuzi-switch`，由测试仓库的构建环境执行打包；不使用测试更新密钥替代正式密钥。安装前先保存创作并退出旧版，保留原有账户与项目数据。

第三方模型的可用性、返回格式、计费及思考内容由供应商决定。支持平台的构建通过不等于所有设备均已实机验收。

## 验证范围与已知限制

- macOS 已实际验证账户连接、文本讨论与两张独立图片规划、任务落画布、Gemini Omni 视频生成、播放/拖动/导出及重启恢复。
- Windows/Linux 提供构建与自动化回归结果，尚未覆盖用户实机完整验收；本地 Codex 已验证连接切换，当前轮次未完成真实推理；音频生成未在本轮实测。
- 备份覆盖恢复的跨存储失败回滚、自定义工具导入统一校验仍待完善；请勿将本次发布理解为全部功能已通过验收。
- 左侧“图片”按钮只导入图片；导入本地视频请使用“素材库 → 上传 → 插入”。部分 macOS 文件选择器仍允许在图片入口选视频，随后会显示格式错误。

# 匿名使用统计交接文档

## 背景

Tuzi Switch 新增最小化匿名使用统计，用于了解正式版的应用启动、供应商管理、代理启停及更新功能使用趋势。

统计默认开启，用户可以在“设置 → 通用 → 隐私与改进”中随时关闭。关闭状态保存在本机，不参与 WebDAV 同步，应用重启后仍保持关闭。

## 用户侧功能

设置页新增“匿名使用统计”开关：

- 默认开启。
- 用户可随时关闭或重新开启。
- 关闭后立即停止触发新的统计请求。
- 设置保存失败时恢复原开关状态。
- 历史设置文件缺少该字段时按开启处理。
- 用户明确关闭后保存为 `false`，不会被默认值覆盖。

设置说明明确告知用户：

- 仅统计应用版本、系统类型和核心功能使用次数。
- 不收集密钥、对话、请求内容、供应商地址或文件路径。

## 统计事件

当前仅允许以下事件：

| 事件                | 触发时机         | 允许属性                   |
| ------------------- | ---------------- | -------------------------- |
| `app_started`       | 正式版应用启动   | 自动附加应用版本、系统类型 |
| `app_selected`      | 用户切换应用     | `app`                      |
| `provider_action`   | 供应商增删改切换排序测试 | `app`、`action`、`result`、`source` |
| `proxy_action`      | 代理、路由、故障转移、熔断 | `app`、`action`、`result`、`enabled` |
| `auth_action`       | OAuth 登录/退出  | `app`、`action`、`result`  |
| `config_action`     | 配置导入导出、备份恢复 | `action`、`result` |
| `webdav_action`     | WebDAV 测试、上传、下载 | `action`、`result` |
| `update_action`     | 更新检查、下载、安装 | `action`、`result` |
| `setting_action`    | 目录、终端、开机启动 | `app`、`action`、`result`、`enabled` |

`app` 仅允许：

```text
claude
claude-desktop
codex
gemini
opencode
openclaw
hermes
```

`source` 仅允许：

```text
manual
tray
failover
```

## 前端实现

### 统一统计入口

`src/lib/analytics.ts` 提供统一的 `track` 方法：

- 仅正式构建允许发送。
- 校验事件名称白名单。
- 校验属性名白名单。
- 裁剪属性值长度。
- 同一事件短时间内进行轻量去重。
- 用户关闭后在前端立即熔断。
- 统计失败静默处理，不影响业务流程。

业务组件不直接请求 Umami。

### 设置界面

`src/components/settings/AnonymousAnalyticsSettings.tsx` 负责展示匿名统计开关。

设置通过现有自动保存流程持久化。开关变化时，前端先即时更新统计模块状态；保存失败后恢复原状态。

### 事件接入点

- `src/main.tsx`：应用启动。
- `src/lib/query/mutations.ts`：新增供应商、手动切换供应商。
- `src/App.tsx`：托盘切换及故障转移切换。
- `src/hooks/useProxyStatus.ts`：代理启动和停止。
- `src/lib/updater.ts`：检查更新和更新成功。

## 后端实现

`src-tauri/src/commands/analytics.rs` 提供统一后端命令：

```text
analytics.trackProductEvent
```

后端执行以下保护：

- Debug 构建不发送统计。
- 每次发送前重新读取本地设置；用户已关闭时直接返回。
- 固定请求地址为 `https://umami.tu-zi.com/api/send`。
- 固定网站 ID，不接受前端传入目标地址。
- 使用严格事件和字段结构校验。
- 拒绝未知字段。
- 限制事件并发数和发送频率。
- 使用复用 HTTP Client。
- 连接超时 2 秒，整体超时 3 秒。
- 不建立事件持久化队列。
- 不重试，不阻塞主要业务流程。
- 不在日志中输出统计请求体。

## 隐私边界

禁止采集：

- API Key、Token、Cookie。
- 对话、提示词、模型请求及回复。
- 供应商自定义名称、地址和请求头。
- 本地文件名、文件内容和路径。
- 用户名、机器名和系统账户信息。
- 配置正文、原始错误正文和完整错误堆栈。
- 永久设备 ID。

请求中使用固定匿名字段：

- 固定 hostname 和页面路径。
- 固定客户端 User-Agent。
- 固定匿名 IP 字段。
- 仅发送操作系统、应用版本及白名单事件属性。

反向代理和 Umami 服务端仍需配置访问日志脱敏、IP 最小化及合理的数据保留周期。

## 配置兼容

Rust 设置字段：

```rust
#[serde(default = "default_true")]
pub anonymous_analytics_enabled: bool,
```

对应本地 JSON 字段：

```json
{
  "anonymousAnalyticsEnabled": true
}
```

兼容规则：

- 旧配置缺少字段：默认开启。
- 新用户：默认开启。
- 用户关闭：保存为 `false`。
- 重启应用：保持用户明确选择。

## 运维注意事项

- 开发模式不会向 Umami 上报，真实数据必须由正式版产生。
- Umami 数据可能存在几秒到一分钟延迟。
- 服务端应定期检查日志脱敏和数据保留策略。
- 新增事件前必须同时更新前端白名单、后端白名单、字段结构、自动化测试及本文档。

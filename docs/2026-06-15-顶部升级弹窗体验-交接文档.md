# 2026-06-15 顶部升级弹窗体验交接文档

## 问题描述

顶部标题旁已有更新图标，但点击后只跳转到「设置 > 关于」。用户期望与 Codex App 类似：有更新时顶部出现按钮，点击后直接弹出更新弹窗，下载时显示进度，安装完成后提示重启。

## 修复思路

- 保留现有 `UpdateProvider` 自动检查更新链路，不新增后端接口。
- 将顶部 `UpdateBadge` 从纯跳转按钮升级为更新弹窗入口。
- 弹窗复用 `updateHandle.downloadAndInstall()`，通过 updater 进度事件展示下载进度。
- 原生更新安装完成后显示「立即重启 / 稍后重启」。
- GitHub Release fallback/manual 更新仍打开下载页，不误提示已自动安装。
- 保留「关于」入口，方便用户查看完整更新信息。

## 更新代码架构

- `src/components/UpdateBadge.tsx`
  - 新增更新弹窗、下载进度、安装完成重启动作。
  - 使用 `useUpdate()` 获取全局更新状态和 `updateHandle`。
  - 使用 `relaunchApp()` 执行重启。
- `src/App.tsx`
  - 更新 `UpdateBadge` 回调名为 `onOpenAbout`。
- `src/i18n/locales/*.json`
  - 补充顶部更新弹窗与下载进度文案。
- `tests/components/UpdateBadge.test.tsx`
  - 覆盖顶部按钮弹窗、下载完成后重启入口。

## 注意事项

- 本次不修改发布工作流、不修改 Tauri updater 配置。
- 本次不读取或写入用户本地 API 配置。
- 顶部按钮仍只在检测到新版本时显示。

## 实现与适配

- 图片/视频生成草稿在原位置变为进度卡，完成后变为结果；批量图片另外分配位置，引用连线跟随进度和结果。
- 失败或取消后的进度卡支持恢复编辑；复制、撤销、重做及重载只修改画布，不重新发送生成请求。结果保留原输入，支持继续调整。
- 恢复历史输入时按原供应商加载模型目录；原供应商关闭或失效时不擅自替换。图片参考端口点击菜单保持打开。
- Seedream 5.5 继续编辑带入上一轮结果与历史参考，保留分辨率档位；直接进入图片生成，避免桌面讨论开关把编辑误送进讨论。
- OCR 图层可转为可编辑文字，坐标随原图移动/缩放/旋转，保留原栅格层并支持撤销；导出清单包含可编辑文字信息。
- 分层中断后可通过请求 ID 获取已有结果，不重新 POST。保留桌面原有尺寸、原供应商、预览、参数校验及应用到画布步骤。
- Gemini Omni 以完整 UTF-8 JSON 检查 1 MiB 请求上限，计入 Base64、提示词与多张参考图；只压缩提交副本，保留原图开启时明确拒绝超限请求。其他视频型号不受新增限制，无新增持久字段或依赖。

没有用网页分层弹窗覆盖桌面弹窗。桌面 SVG 与网页 HTML 是不同的渲染路径，本轮分别补齐图片和视频卡的恢复编辑按钮。桌面常规图片批量预览保留，原位生成不再走常规批量预览的自动平移。

桌面结果恢复继续遵守现有请求 ID 节点限制：仅在支持的可信节点启用；不支持的节点保留明确失败，不展示不可用的恢复句柄。GET 恢复持有本次请求原始配置的内存快照，不切换到后来修改的供应商，不把认证信息写入画布或文档。真实服务端是否保留完整分层元数据仍需要对应环境联调证明。

网页版本号、发布记录与本轮无关；原先排除的 Flash/GPT26 模型分支不夹带导入。桌面讨论视频关键帧、画布控制、视频文件菜单、更新提醒及 ChatGPT MCP 接入实现保留。

## 字段兼容

| 字段 | 传播与兼容 |
| --- | --- |
| `generationOrigin: {version: 1, draft}` | 可选画布字段，随进度卡与图片/视频结果持久化；复制时重映射引用；已有递归媒体备份覆盖嵌套媒体；旧元素走原路径。 |
| `requireExactModelRef` | 可选输入恢复事件字段，只用于保持原供应商；不修改服务端协议。 |
| OCR 结构与 `metadata.semanticText` | 有效 OCR 归一化供文字编辑，旧/未知 OCR 原值继续保存；文字对象记录来源层、位置和近似样式，清单一并导出。 |
| `allowImageSubmissionRetry` | 可选传输参数；分层明确禁止 POST 重放，允许查询已有请求。 |
| `LayerRecoveryHandle` | 仅当前弹窗内存持有，不持久化凭证；恢复期间锁定原始参数。 |

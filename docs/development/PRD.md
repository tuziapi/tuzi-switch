## 目标与产品范围

用户从助手用系统默认浏览器前往 API 网站，复制自己的账户系统令牌，回跳后按 B11 条件预填（或手动粘贴），确认并连接。原生层验证身份、保存到独立本地账户配置文件并直接调用原站业务接口。B13按用户明确要求使用本地明文JSON及文件权限，不再访问系统钥匙串，也不调整授权弹窗流程。旧钥匙串用户首次更新后需重新粘贴一次；此后正常切页和重启不要求重新粘贴。文件读写失败明确报错。系统令牌不是模型 API Key，不自动配置到工具。

## 网站取令牌完整流程

1. 助手连接区有“前往获取系统令牌”和粘贴连接入口，说明账户系统令牌与模型 API Key 不同，并提示其账户级权限。
2. 系统浏览器打开固定可信地址 `https://api.tu-zi.com/console/personal?source=tuzi-assistant#system-token`，URL 仅含来源/定位信息，绝不含令牌。
3. 已登录直接进入个人设置安全区域；未登录走现有密码、验证码、2FA/Passkey/其他既有登录，登录后回到同一可信站内路径、查询和锚点。返回目标严格规范化，不允许开放重定向。引导参数只影响展示。
4. 渲染后滚动并定位系统令牌卡片，用贴边细蓝边及淡蓝背景强调约2秒，再用约400ms淡出；深浅主题适配，减少动画时取消平滑滚动与过渡。保留输入/按钮键盘焦点提示；普通个人设置默认行为不变。
5. 自动读取已有令牌，可查看/隐藏、复制；读取失败可重试，不假装没有令牌，不自动生成。没有令牌时明确让用户主动生成。
6. 重新生成是独立确认操作，说明旧令牌立即失效并可能影响其他共享接入；复制已有令牌绝不轮换。从助手引导进入时，成功复制先提示“已复制，正在准备跳转兔子助手…”，等待1.5秒后尝试打开固定 `tuziswitch://account/connect`，回到账户页，并保留“打开兔子助手”手动入口；普通个人设置只复制。卡片介绍固定为“用于API调用的身份验证令牌，可以用此连接兔子助手，请妥善保管”。剪贴板失败提供可选择文本，登录失效提供保留定位的重新登录入口。
7. B11：用户点击助手“获取系统令牌”后，5分钟内通过固定深链回跳、仍未连接且输入框为空时，尝试一次读取剪贴板并遮罩填入网站格式的系统令牌；已有输入不覆盖，过期/失败/格式不符/冷启动则手动粘贴。用户仍需确认并点击“连接”，显示验证中/成功/错误。未连接卡片居中、按钮对齐，空值或空白校验用约 3.5 秒短暂提示，不占正文位置。失败允许重试或修改，输入在完成流程前短暂保留；成功、取消或离开连接流程时清敏感值，不进入前端持久缓存。网站不自动回传令牌，不做 OAuth 回调。

## 身份、状态与边界

| 状态/操作 | 产品行为与验收边界 |
|---|---|
| 未连接 | 工具照常可用，账户区显示粘贴连接流程，不显示前账户数据 |
| 验证中 | 原生仅凭令牌引导身份，不让用户手动复制 ID；验证及安全保存完成才成功 |
| 已连接/重启恢复 | 原生恢复本地配置记录并回读当前身份；前端普通查询取不到保存的令牌 |
| 网络失败/离线 | 明确网络错误，可重试；不直接认定凭证失效，不伪造零消费 |
| 令牌失效/轮换/账户禁用 | 停止账户请求并提示重新连接或账户不可用；无 OAuth 刷新、到期或自动轮换 |
| 旧钥匙串记录 | 不读取、不自动迁移、不删除；首次使用本地文件版本需重新连接，不把旧 AT/RT 当系统令牌 |
| 本地断开 | 以空 v2 记录覆盖本地账户文件中的令牌/身份，清账户缓存/草稿和临时 Key；覆盖失败明确报错，不声称网站令牌已撤销；工具和网站登录不受影响 |
| 切换账户 | 单一活跃账户，清旧状态并递增代次；迟到响应/写回不能污染新账户；已发送写操作结果可能待核实 |
| 业务失败 | 同时检查 HTTP 和 `success:false`；401、账户禁用、403、429、5xx 和空数据分别处理 |

固定 API origin；不依赖浏览器 Cookie、不转发凭证跨域、不允许任意管理接口代理。首次身份引导只新增窄 bootstrap，后续保留原站用户 ID Header 校验。系统令牌按账户角色拥有实际权限；管理员连接后，助手所有本人查询仍强制当前用户，不聚合全站。隐藏页面、静态 `X-Tuzi-Client`、客户端白名单不能降低令牌泄露后的服务端权限。

## 业务保留要求

余额、额度、累计消费及今日已记录消费明确来源、金额单位、精度、时区与时间戳。总览用完整服务端汇总，不累加有上限的模型列表。今日调用指 type2 消费记录，可能含收费失败；type6 错误和 type7 退款分开，退款可能对应早先周期。日志不可用/关闭/清理不能视为已确认零；无完整性证据固定说明“已记录消费，非完整账务”，延迟未知如实标注。

Key 保留列表/搜索/分组/分页/创建/详情/查看复制完整模型 Key/编辑/启停/删除/回读。无 Key 时仅表格内显示密钥空态，不显示中间消费占位。创建、详情、编辑、揭示使用独立弹窗；详情只读，点击“编辑”才填入编辑表单，迟到详情不能污染创建草稿。默认只填名称和分组，默认不限额度、永不到期；高级金额、日期、模型和 IP 条件折叠。删除必须点击“确认删除”后才发请求，取消/Esc 不删除，重复点击去重。额度默认人民币，可切 USD，当前币种用蓝底白字明确激活，换算使用站点真实元数据；永久到期显示“永不到期”。简化编辑由服务端原子部分更新，缺省保留，零/false/显式清空有效，未知或 null 拒绝；不得 GET 合并 PUT 覆盖网站并发高级字段。完整模型 Key 只在用户主动查看/复制/配置时短暂存在，不进入普通缓存或 URL，不能与账户系统令牌混用。

日志仅本人普通筛选、分页和请求摘要，不返回完整内容或管理渠道诊断。模型广场保留可见分组、个人价格、协议与复杂计价；匿名价标参考，缺价不等于免费。性能保留 1/6/24 小时、毫秒/每秒 Token、成功率及历史时间，无样本/无 TTFT 为 null。管理员的站点原接口可能有更宽字段，原生投影必须维持助手既有普通业务视图。

资料仅主动保存五字段：`display_name`、`language`、`accept_unset_model_ratio_model`、`high_concurrency_enabled`、`record_ip_log`。价格设置保留网站费用风险、默认和账户限制；服务端锁内合并 settings，未知字段、null 和权限字段拒绝。通知/边栏/签到/密码/绑定/2FA/Passkey/系统令牌轮换/删号仍在网站处理。

配置到工具保留现有创建表单、站点/用户/token/provider 来源证明、协议/端点/分组检查、后台变更计划、完整写集备份与失败补偿；安全检查不能因 B 而旁路。历史来源不能按名称/掩码推断。保存、启用、用户主动测试分开；不做付费调用。B09 公开每条 Key 的独立突出“配置”按钮，列出现有可配置工具（按平台过滤），每项左侧名称和配置状态、右侧现有工具图标，再按密钥状态、分组、模型限制及协议过滤模型。已知来源且供应商仍存在时标记“已配置 · 查看配置”，点击定位现有工具配置，不重复创建；新配置打开对应工具的“兔子线路”表单，预填所选 Key/兼容模型、名称和图标，保留独立凭证索引及原事务。B11 修复分类丢失和附加工具标识缺失；B12 按用户确认统一添加体验：点击表单“添加”即执行后台计划、校验、备份和保存，不再展示额外变更确认框。准备及保存期间阻止重复提交和关闭，失败保留表单并提示原因，重试重新生成计划。B15（2026-10-19）：新建供应商默认名称为“兔子线路-密钥名称”（去首尾空白，无名称时回退“兔子线路”），保留用户编辑及已有配置名称。保存后停留对应工具页并定位配置；成功提示只显示保存/启用结果，不提供“恢复配置”操作，后台备份与失败补偿保留；B10 按用户确认移除工具页整块“返回兔子账户 / 配置保存后，可在此启用或检查”提示，通过顶部兔子账户入口返回。定位采用卡片内细边/淡背景约2.4秒后淡出，独立于实际启用状态；列表刷新不重复滚动，再次查看可重新定位，减少动画设置下不平滑滚动或渐变。

网页固定入口：钱包及兑换 `https://api.tu-zi.com/console/topup`（兑换受站点开关，不虚构锚点）；资料 `/console/personal`；Coding `https://coding.tu-zi.com/reseller/`；GACCode `https://gaccode.com/subscriptions`。不携凭证、不自动提交，提醒网站账号可能不同；回来只刷新当前助手账户，不推断充值成功。

## B13：本地账户文件与 Codex 隐藏环境变量（2026-10-19）

批准来源：用户明确“保存为一个配置文件，而不是修改授权流程”，并要求“环境变量那一块也一起改”。决定见 [ADR-011](decisions/0011-local-account-file-and-hidden-codex-env.md)。

只有Codex展示独立“环境变量名”输入；新增/编辑移除输入和说明，高级设置不保留该独立字段。底层配置和原始配置编辑器继续保留引用；新建自动生成合法、不重名的变量名；编辑使用原配置引用，不随端点/名称/模型变更而重命名或迁移；真正缺失的旧配置保存时补齐，并保留其原模型Key。异常旧引用不静默改名，提示重新导入有效配置或新建供应商。保存失败不伪报成功或丢弃密钥。Claude认证字段、Gemini环境编辑和其余工具配置机制不变。

## B15 账户连接反馈（2026-10-19）

保留原生重新验证已保存系统令牌的能力，入口改名“检查连接”，等待时显示“正在检查…”并禁止重复点击。仅已验证 connected 且有身份、无错误时提示“连接成功，兔子账户可正常访问”；离线/失效/断开和 IPC 错误提示检查未通过与安全错误文案。账户切换后的过时结果和离页后的结果不得误报成功；不加载或展示原始错误详情。

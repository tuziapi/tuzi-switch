# 开发 PRD：兔子账户中心与工具管理

版本 `TA-AC-1.5-B3`，对应原产品方案 v1.5；本轮确认差异见 ADR-001。此文只描述目标行为；当前实现情况由 source-audit 说明。

## 目标、范围与非目标

在现有七种工具管理之外增加兔子账户中心，让用户通过系统默认浏览器一次授权，原生查看和管理主站账户、Key、调用明细、统计、模型状态、模型广场和确定的资料项。账户连接由原生层自动维护，正常切页、刷新、重启不重复授权。

账户导航：总览、API 密钥、调用明细、模型服务状态、充值、兑换、个人资料、模型广场。工具导航及七种工具 Claude、Claude Desktop、Codex、Gemini、OpenCode、OpenClaw、Hermes 的供应商、MCP、提示词、Skills、会话、工作区、设置及工具专属能力按现状保留。主站总览与本机状态分别标注数据来源和更新时间。

2026-10-15 用户确认导航呈现调整（T12-N01）：保留原兔子switch顶栏，将“兔子账户”放在工具切换栏最左侧，与七工具平级；移除单独的“兔子账户 / 工具管理”分区栏。账户页保留同一顶栏和账户内部导航，工具页继续保留原功能。沿用根据实际可用宽度自动收起名称的规则，窄窗口显示图标及名称提示；账户选中时不同时选中工具，从账户可直接返回之前所选工具。此项只调整导航呈现，不新增业务范围或修改 B3 / desktop-v1.1 契约。

2026-10-15 T12-N01 后续修订：用户要求去掉账户侧边栏顶部重复的“兔子账户”图标与标题块，账户内部导航从“总览”开始，保留底部连接状态；工具切换动画完成后也须按实际内容宽度重新判断收起，避免 Hermes 切换到 OpenClaw 时右侧操作被截断。

本期不新增独立订阅、订单、邀请返利模块，不接商城/分享站统一身份，不建通用 OIDC、双授权中心、全局退出或资产迁移，不重写模型转发/支付/工具配置体系，不开发 Coding/GACCode 用量 API 集成。源码有批量 Key、日志导出、完整请求内容等接口不自动纳入首版；请求详情仅作本人请求摘要（Q08 列明扩展边界）。

## 行为边界

| 执行方 | 负责 | 边界 |
|---|---|---|
| React 客户端 | 导航、页面状态、分页筛选、脱敏展示、用户操作、现有表单 | 不持有长期账户 Token，不信任 UI 隐藏替代服务端鉴权 |
| Rust 原生层 | 受信授权配置、随机 state/PKCE、回调、换码、userinfo、scope、系统安全存储、刷新、撤销、账户请求 | 不复用工具 OAuth/模型 Key；不接受页面指定任意凭证发送目的地 |
| API 站 | 独立公共客户端、网站授权、逐接口 scope、本人归属/字段、寿命与撤销、限流/清理 | 管理员在桌面授权下也只能访问首版本人能力 |
| 浏览器 | 原站登录、验证码、2FA/Passkey 等既有验证、一次授权、充值兑换/敏感资料 | 浏览器会话不交给客户端；网站账号与桌面账号可不同 |
| 本地工具 | 原有模型调用、供应商/工具认证、已保存配置 | 退出兔子账户不自动停止模型调用；禁用/删除 Key 是独立动作 |

凭证严格区分：桌面 OAuth、主站模型 Key、旧系统访问令牌、`/coding` Key、GACCode Key、工具自身 OAuth。主站 Key 只能在目标工具适配主站协议/端点/分组时配置；不能因为工具名是 Codex 就写入 `/coding`。

## 用户流程与页面状态

登录：点击连接 → Rust 建立待授权事务 → 默认浏览器 `/oauth/authorize` → 必要的原站登录/二次验证 → 显示可信客户端名、当前账号和完整首版 scope，一次同意 → `tuziswitch://auth/callback` → Rust 验证 state、换码、验证 userinfo 及完整 scope → 保存凭证 → 已连接。取消、超时和重复回跳不能改变已有工具配置；重新发起需使旧事务失效。

| 状态 | 展示/操作 | 验收边界 |
|---|---|---|
| 未连接/取消 | 账户入口提示登录，工具正常可用 | 不展示前一个账号数据，不自动授权 |
| 等待浏览器/换码/验身份 | 进度、取消、超时后重试 | “回跳收到”不等于“已连接” |
| 已连接 | 全首版必要权限齐全，页面按需读取 | 正常切页不追加权限申请 |
| 刷新中 | 同一连接复用一次刷新，避免页面各自重登 | 安全持久化新凭证后放行等待请求 |
| 离线 | 可显示当前账号允许缓存的非敏感数据，标注缓存与时间 | 无缓存显示离线，不伪造零值；不修改远端状态 |
| 授权失效/撤销 | 停止旧请求和旧授权缓存展示，必要时重新连接 | 401 只做有界刷新；403 不刷新；不可恢复不循环 |
| 权限/版本/账号策略异常 | 明确缺权限、账号限制或服务端配置问题 | 只有重新授权能够恢复时才提供恢复入口 |
| 接口不可用/限流 | 局部错误、重试/退避；其他可用功能不误报成功 | 不展示成空数据；尊重 Retry-After |
| 退出/换账号 | 清凭证、账户缓存、内存 Key、预填草稿；保留供应商 | 离线退出明确服务端撤销未完成，网站可撤销连接 |

账户切换采取先断开旧连接再授权新账号；不新增多账号同时活跃产品。网页返回/窗口聚焦只刷新当前桌面身份，不从浏览器推断充值成功或自动换账号。

Key 配置：本人 Key 列表 → 配置工具 → 选择支持的目标工具 → 按需 reveal → 现有添加供应商表单预填 → 查看脱敏变更与备份结果 → 用户保存 → 返回原列表，展示实际保存/启用状态。取消、换账号、授权失效清理未保存 Key。保存不代表连接测试通过；模型测试由用户主动触发。历史供应商不因名称/掩码相同自动归属当前账号。

## 原生资料与网页入口

原生读取基础资料和可用设置，原生编辑白名单：`display_name`、`language`、`accept_unset_model_ratio_model`、`high_concurrency_enabled`、`record_ip_log`。已由用户本轮确认。价格开关保留网站说明、默认行为和账号限制，只有主动保存才变更；“接受未设置价格模型”的费用风险说明不能省略。高并发开关不等于绕过网站余额/权限阈值。

通知（含通知渠道凭证）、边栏、签到、密码、改绑/绑定、2FA、Passkey、系统访问令牌、删号等全部网页管理。不得把整个 user.setting 或 UpdateSelf 请求透传为桌面资料写接口。账户 username/id 不提供原生修改。

| 入口 | 固定目标 | 行为 |
|---|---|---|
| 充值 | `https://api.tu-zi.com/console/topup` | 默认浏览器；提醒核对网站账号；按当前桌面身份回读 |
| 兑换 | 同钱包页兑换码区域 | 受实际站点开关控制；无已核实锚点时不编造 URL；绝不进管理员兑换码页 |
| 网页资料 | `https://api.tu-zi.com/console/personal` | 保留网站验证，客户端不自动携带凭证 |
| Codex 订阅用量 | `https://coding.tu-zi.com/reseller/` | 独立 Key/账户；不拼 Key、不自动提交 |
| GACCode 积分 | `https://gaccode.com/subscriptions` | 独立 Key/积分；不并入主站数据、不自动提交 |

## 2026-10-15 首期分阶段开放（用户确认）

兔子助手首期只公开“API 密钥”和“总览摘要”工作区。账户页不显示侧边栏，固定进入 API 密钥页；总览的账户余额、今日消耗、今日消费调用、今日 token 四项摘要放在密钥筛选区上方。调用明细、模型服务状态、模型广场、个人资料、充值、兑换及其他账户页作为后续阶段隐藏。

本调整只影响兔子助手的 `/api/desktop` 能力；API 站原有普通用户控制台、登录、安全、支付和其他网站页面保持不变。首期隐藏同时由 API 桌面路由闸门和客户端展示层执行，隐藏页面不得因直接请求或旧页面状态而可用。API 密钥页首期不显示“配置到工具”入口，避免依赖未开放的模型能力。

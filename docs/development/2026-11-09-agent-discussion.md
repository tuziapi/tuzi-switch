## 实现

- 30px 单行状态栏直接放在主输入框内部顶部，同宽贴合，显示真实接口返回的 reasoning 摘要或回复/生成进度，点击打开并排讨论，运行中可停止；不生成模拟思考文案。
- 主输入框的 Agent 自动模式与侧栏讨论复用同一画板关联会话、现有文本模型配置、四协议流式传输、附件与消息存储。两个输入框的草稿独立。
- 复用已有 Agent 执行器和图片/视频工具；完整 JSON 计划校验后提交现有任务队列。每轮合计最多 10 个作品，普通讨论不要求调用工具。执行语义仍是现有 Agent 的单轮计划与工具执行，非新增无限自主循环。
- `textChat.executionMode/linkedBoardId`、消息 `origin/discussion`、任务 `params.conversationLink` 均为可选字段；旧纯文本会话保持原行为。恢复时校验画板、运行、任务引用，环境备份保留字段。
- 任务在提交之前带上来源画板/会话/运行/消息身份，结果由原有插入流程放回原画板。切换画板后等待返回；聊天卡片读取同一任务与桌面缓存，支持定位及仅同步已有结果，不重新生成。
- 讨论不提供一键重放整轮生成，防止恢复中遗漏任务列表时重复扣费；通过发送新消息继续讨论。已删除画布作品不自动补插。
- 并排侧栏打开时主输入框避让，侧栏默认最多 440px，窄窗口不超过一半；不因流式 token 刷新整个画布。保留原节流、隐藏订阅暂停、长会话虚拟列表。
- 讨论媒体完成绕过旧工作流自动关闭抽屉/移动视口逻辑。提前初始化聊天两个存储表，避免首次媒体任务查询旧消息时升级数据库打断聊天保存。

# Claude Desktop 模型目录与启动检查

任务：CL-LOCAL-MODELS-01 / CL-LOCAL-MODELS-02。日期：2026-11-17。下方 MODELS-01 为已安装的历史记录；最新统一选择改动见 MODELS-02，尚未替换用户正在测试的本地应用。

## 用户行为

保存供应商时使用该线路现有地址和 Key 获取完整模型目录，支持分页。列表默认筛选 Claude 并显示 10 项，可搜索全部目录、展开全部和选择默认模型。选择“全部模型”可查看供应商返回的其他模型；自动路由仅纳入 Claude 名称，其他模型仍通过高级映射显式配置。

默认模型优先显示；供应商提供有效时间时按时间降序，未知时间按名称自然排序，不宣称前 10 项就是“最新 10 项”。目录是供应商自报数据，不能据此证明模型身份、权限或桌面功能全部可用。

保存自动补全 Claude 路由，保留手动别名、映射和上下文标记；有效默认选择优先保留。刷新失败不保存，用户可以修正后重试，或明确选择手动映射保存。改变地址或 Key 会使内存目录失效。首次空映射时，启动页显示“配置模型”，避免直到启动才报缺少路由。

## 实现与兼容

- 原生 `fetch_claude_desktop_models` 单独使用禁止重定向的代理兼容客户端；Authorization 与 x-api-key 仅发往配置端点。分页只追加 after_id，不跟随服务器提供的 URL。
- 请求总时限 60 秒，每次最多 15 秒、每页 8 MiB、最多 100 页或 20,000 条。超过边界或游标重复明确失败，不静默截断。
- 错误只带状态或固定描述，不返回响应正文或 Key；共享旧模型获取路径行为不改。
- 新增可选 `meta.claudeDesktopModelCatalog: [{id, createdAt?}]` 和返回 DTO 的 `createdAt?`；Rust serde、TypeScript、中英日文案及旧配置兼容测试均已补齐。仅存 ID 和时间，无数据库表迁移。
- 默认模型复用 `env.ANTHROPIC_MODEL`；兼容核心按上游模型或路由 ID 解析默认项，兼容 `[1M]` 后缀。会话仍使用启动快照，修改需下一次启动生效。
- 缓存只在本次表单内对相同凭证有效 5 分钟；持久目录用于展示，重新打开后保存会重新获取。

## CL-LOCAL-MODELS-02：统一模型选择（2026-11-17）

用户明确选择“推荐：统一模型选择”，覆盖此前默认 10 项及仅 Claude 自动映射的交互。实现范围：

- 默认显示完整目录，保留搜索和列表滚动；默认模型置顶，其余有发布时间时按时间排序，不按厂商优先。
- 选择非 Claude 对话模型时，自动生成 Claude Desktop 可识别的内部别名；真实上游 ID 原样保存。别名碰撞追加序号，不覆盖既有映射；客户端显示真实模型名或用户指定的显示名。
- API 协议常驻表单，由用户选择或复用供应商预设/保存值；不根据厂商品牌猜测。复用 Anthropic Messages、OpenAI Chat Completions、OpenAI Responses、Gemini generateContent 四种既有协议配置。需要映射或协议转换时自动选择本地路由模式，保留已有 proxy 配置。
- 两套手动编辑器合并为“手动添加模型”；没有目录接口时，获取失败后可显式按手动配置保存。此轮没有新增 Gemini 原生目录协议，原生 `/models` 不符合既有目录格式时仍需手动填写。
- 目录仍显示明显的绘图、转写、TTS、向量、重排等专用模型；按已知名称标为非对话并禁选。名称识别是保守提示，不是能力认证；未知厂商模型可选，不承诺工具调用、图片理解、上下文或电脑控制已通过实测。
- 更换地址/Key 或刷新目录会清除失效的自动映射（由目录成员、生成别名、默认显示名且无显式 1M 标记识别）。自定义别名、显示名和上下文标记保留。旧 direct 配置仍按原 route ID 的实际语义读取，避免无效的历史 upstream 字段改变路由。
- 全部复用已有 meta/env 字段，无新增持久化字段、数据库迁移或新原生 DTO；中英日文案同步。新增手动模型在自动获取成功时也不会丢失。

### 客户版本不兼容时的当前行为

兼容启动仅接受源码白名单版本 5.11492.5（Windows 也接受对应四段版本）。Mac 优先使用已验证的独立副本，首次准备时从已安装官方包复制；Windows/Linux 校验已安装客户端。没有自动下载并升级至兼容版本的流程。独立 Claude Code 工具入口提供版本显示/检查和安装命令指引，不能视为不兼容自动修复。

建议后续实现“检测 → 展示已验证目标版本 → 一键下载 → 签名/摘要及版本校验 → 安装/准备 → 再检测”，并纳入干净机器、失败恢复与回退验收；尚未作为已交付功能。

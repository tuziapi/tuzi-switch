## 使用行为

- 主输入框上方讨论区增加“连接本地 Codex”。未连接时保留原 ModelSelector；连接后显示 CLI 可用文本模型、思考强度和断开按钮。
- 启用状态限本次应用运行。原模型配置不改写；初次探测失败保持原路径，已启用后请求失败明确报错，绝不自动换到其他供应商。
- 规划仍走原有校验与预览确认，最多 10 个任务；图片/视频/音频继续使用底部选择的执行模型并关联原画板，文本默认保留讨论中。
- 只呈现实际回复增量和可用的思考摘要。没有摘要不伪造内容；不展示内部原始事件或敏感配置。
- 连续讨论复用兔子保存的上下文。每轮创建短生命周期的 ephemeral Codex 线程，结束后回收进程，空闲无新增 CLI 常驻服务；不读取用户其他 Codex 会话。
- 修复生成结果选中后编辑草稿覆盖下一条讨论的问题；讨论中的选中作品只作引用。早期校验失败保留主输入框草稿。

## 原生与兼容

- 增加 `creative_codex_probe/chat/cancel`，仅接收模型、强度、限制长度的文本和图片数据。不接受来自 WebView 的任意命令、路径、凭证或服务地址。
- 使用固定 CLI 参数/stdio；复用 CLI 自己的现有认证，不复制登录文件。讨论模式关闭 shell、插件/应用、hooks、内置图片工具及继承 MCP 服务；只读沙箱，拒绝工具执行审批。
- 子进程在后台线程运行，限制同时任务数、输出大小、协议行长度和总时间；终止时发送 interrupt 并回收进程。通道完成事件与命令返回分离，处理停止早于注册的竞争。
- 每轮固定连接代次，等待保存期间若发生断开/重连则不再发送旧轮次；回复失败不会自动重试付费请求。
- `CreativeAccountBridge.localCodex` 是可选宿主能力，与兔子账户登录独立；旧宿主无该能力仍走原配置。连接代次及选择只在内存中，新增消息沿用已有 `model` 字段标记 `Codex · 模型名`，无数据库/备份新字段或服务端契约变更。

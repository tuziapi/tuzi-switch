# UC-AGENT-CHAT-05 输入框上方讨论

用户在三种交互原型中选择第三种「输入框上方展开」，并明确删除底部工具栏的讨论按钮。仅本地实现、验证、构建；不推送、不发布、不新增真实模型调用。基线 `efac7cc127f6c1da3703b12c39ca8fbb934df3f3`，保留当前工作区已有修改。

## 实现

- 顶部 30px 窄条同时负责打开、收起；面板与主输入框左右对齐、向上展开，不增加页面遮罩，不压缩画布。
- 展开时主输入框固定在画布底部，仍保留选中作品上下文，避免跟随图片后没有足够阅读空间；收起恢复既有定位行为。
- 同一主输入框继续发送 Agent 讨论，复用配置内文本模型、现有流式输出/模型返回的推理内容、生成任务和原画板归属。不另挂载聊天输入框或第二个模型选择器。
- 复用既有会话记录渲染、长记录虚拟列表、Markdown、保存和任务结果；收起卸载记录视图但不停止后台请求。
- 当前画板历史、新讨论、重命名、删除、放大阅读、关闭与 Escape；生成结果紧凑展示，定位成功后收起并定位已有作品，不重新生成。
- 独立文本聊天仍保留原来的附件和草稿功能；嵌入讨论使用主输入框既有图片/视频及画布引用，未把旧独立草稿/附件隐式发送给 Agent。
- 新增的组件参数均为 UI 瞬态，不新增数据库字段/服务端契约。原生网络与付费调用逻辑不变。

# UC-TEXT-ATTACH-01 文本聊天附件

2026-11-08 用户明确选择 A：图片、PDF、TXT/Markdown 和代码文件。复用现有文本模型配置；仅本地实施、合成验证及体验包，无 push/PR/发布。此前真实调用额度已用完，本轮真实模型请求 0 次。

## 行为与兼容

输入框回形针选文件、拖入文件、粘贴图片；支持卡片预览/移除、只发附件、上下文、显式重试、草稿及消息重启恢复。预览在创作容器内浮层显示，Esc 关闭预览且保留工作区。上传中切换会话会取消，不会把文件加到新会话。

复用原配置的 OpenAI Chat/Responses、Anthropic、Gemini 协议。文本/PDF 以文件名及提取文字加入上下文，图片转对应协议图片字段。已明确不支持图片的配置拒绝发送；未声明能力的路由仍需以上游响应为准，不能据协议格式认定全部模型可识图。

| 项目 | 本轮边界 |
| --- | --- |
| 文件 | PNG/JPEG/WebP、PDF、TXT/Markdown、界面 accept 列表内常见代码/文本格式 |
| 每条 | 最多 6 个，原文件合计 20 MiB |
| 单图 | 原文件 10 MiB/4800万像素；最长边压至2048，压缩图≤2 MiB，列表缩略图160px |
| PDF | 单个10 MiB/50页，最多8万字符；仅提取文字，不保留原PDF/图表/版式，不做OCR |
| 文本 | 单个2 MiB/8万字符，UTF-8；二进制、空白与无效编码报错 |
| 请求 | 图片数量遵循配置，缺省最多6张上下文；编码图合计12 MiB；文本上下文80万字符 |

消息/草稿仅存引用，正文及缩略图存独立 localforage store；发送前检查记录及会话归属。删除会话和清空记录清理附件；备份新增可选 textAttachments，旧会话/旧备份兼容。错误备份在清除当前数据前拒绝；原有跨存储恢复没有整体原子回滚保证。

## 性能与风险

解析模块、PDF worker、中文字符映射和标准字体均随包按需加载、文件串行处理、图片缩略图与正文拆分、会话快照不含base64/文档正文；超量上下文边读边拒绝。浏览器合成链与本机小样例验证不能保证所有大型PDF/低配硬件零卡顿。PDF不支持的字体/扫描页可能提取不完整，预览可检查实际发给模型的文字。

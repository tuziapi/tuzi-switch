## 实现

- 新 `scripts/install-macos.sh` 固定正式 v1.5.5 和两种 DMG 的 SHA-256；自动识别 Intel/Apple Silicon，包括 Rosetta。仅 HTTPS 官方地址，不使用镜像。
- 安装和放行分别在终端确认；先设置暂存副本隔离标记，确认后才移除该副本隔离标记。没有静默同意选项，不调用 sudo 或全局安全开关。
- 检查下载摘要、应用 ID/版本/架构和 ad-hoc 签名完整性；保护运行中的应用，拒绝降级、未知应用、符号链接和并发安装。复制、完整性验证和放行在暂存目录完成，再移动旧应用至备份；替换失败自动恢复。
- 默认系统应用目录可写时安装到该处，否则选择用户应用目录；支持明确指定目录。旧版配置/凭证/数据库不读取、不迁移、不改写。
- 网页提供已展开的 Mac 脚本、复制命令和脚本下载链接。命令验证脚本摘要后运行，不通过管道执行不完整下载。保留七种直接安装文件选项。
- `macosInstaller` 为可选元数据，含 tag/href/sha256，浏览器严格校验正式渠道和固定版本 URL；构建门禁交叉检查脚本内摘要与真实 Release。后续版本不继承旧安装器。

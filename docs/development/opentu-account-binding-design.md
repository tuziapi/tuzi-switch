## 本地字段与原生边界

为复用现有设置序列化和模型路由，不再实施早期草稿中的独立 modelRoutes/revision 表。既有 providerProfiles 和 invocation presets 继续负责模型路由，账户记录只描述不可变来源。

| 字段 | 位置 / 约束 |
| --- | --- |
| `schemaVersion` | 独立 `creative-account-bindings.json`，固定 1，未知字段/版本拒绝 |
| `id` | 原生 SHA256(origin:userId:tokenId) 前 16 字节，带 `tuzi-account-` 前缀；同来源幂等，不可变 |
| `accountOrigin / userId / tokenId` | 固定兔子站点、当前账号、显式选择的本人 Key；读文件再次校验类型和派生 id |
| `name / keyMask / group / updatedAt` | 显示元数据，时间为 Unix 秒；不代表资格仍有效 |
| `providerProfiles[].apiKey` | 账户模式仅保存 `tuzi-account:<id>` 非秘密引用；普通手动模式保持已有凭证机制 |
| `generation` | 每次 IPC 传当前账号代次，运行期校验；不从关联文件恢复“已连接” |
| 请求字段 | bindingId、requestId(UUID)、upstreamRequestId?、action、model?、taskId?、body?、parts[]；未知字段拒绝。multipart 每项 name/value 或 data(base64)/mime，原生重建边界与文件名 |
| 响应通道 | start(status/content_type/受限 request-id headers)、data(base64)、end；错误仅返回稳定代码 |

系统令牌继续仅由宿主原生账户层访问，模型 Key 只在原生资格校验/请求内存中使用，不返回创作表单。复用原生本人 Key 详情、启用/过期/额度检查、模型权限列表；不创建或覆盖工具配置保存使用的一次性 proof。无新的服务端接口或 DTO。

选择 Key 时先验证并原子写入来源元数据，随后修改供应商草稿；取消草稿可能留下未引用的来源记录，其中没有凭证或调用路由，不启用任何模型。文件最多 200 条、1 MiB，拒绝符号链接和伪造来源；不自动清理旧账户记录或旧钥匙串。确定性来源 id 不会因重新选择而指向另一账号，故无需关联 revision；供应商并发语义沿用原设置管理器，不宣称跨窗口事务。

调用时重新校验来源、代次、Key 和模型目录。POST 必须属于已授权模型并具有匹配端点元数据或明确协议标签；未知能力拒绝，不根据模型名放行。原生动作映射固定 URL，拒绝 renderer URL/headers 和跨域重定向；账户关联不自动切线路、切 Key 或重新提交。图片 multipart、文本流式响应、取消及结果找回走同一桥接。请求体与响应均限 64 MiB，单次上游请求最长 600 秒；大媒体内容仍受该边界约束。

当前动作：模型列表；图片生成/编辑/找回；Chat/Responses；OpenAI 视频提交/轮询/内容；音频 speech/transcriptions；Gemini generateContent/streamGenerateContent。其他专有接口（如 MJ、部分 Flux/Kling/Suno、自定义 HTTP、图片巡检）明确拒绝受管关联并提示手动配置，不能以回填模型密钥绕过。此列表表示本地动作适配范围，不代表全部协议已做真实账户验证。

## 生命周期与兼容

| 场景 | 行为 |
| --- | --- |
| 未连接 / 断开 | 关联保留，停止新请求；画布编辑和手动供应商独立可用 |
| 切号 / 验证期间切号 | 代次检查拒绝旧结果，复用既有 pending 取消机制；不能让旧绑定转到新账号 |
| Key 删除/禁用/过期/额度不足 | 重新校验失败；不静默创建、选用其他 Key |
| 不明结果 / 取消 | 返回待确认提示；已送达服务端的任务不宣称已取消，不自动重试收费操作 |
| 轮询 / 找回 | 使用原调用上下文的来源引用及任务 ID，重新验证 Key；不承诺跨账号恢复或外部任务所有权查询 |
| 导出 / 导入 | 设置含敏感信息导出也剔除账户引用；导入不恢复关联，需重新选择。手动凭证机制不变 |
| 原生功能未接入 | 保持明确失败，无浏览器秘密兜底；源码中既有媒体/任务/安装包门槛仍然存在 |

不启用 opentu 独立系统令牌输入或 `/api/opentu/providers/ensure` 自动供应商创建。早期独立右侧快速面板只作历史画面来源，本轮不再维护第二份设置。

真实账户、付费生成、macOS/Windows/Linux 安装包端到端和跨窗口并发尚需另行验收。回退只停用桥接并保留新来源文件、手动供应商及项目，不将秘密回填旧设置。

## 实际复现与根因

1. 在已安装 `/Applications/兔子助手.app` v1.5.7 中，内联图片可以预览，但复制/另存为显示 `Load failed`。正式 CSP 允许 `img-src data:`，不允许 `connect-src data:`；菜单、生成缓存和大参考图压缩错误使用 `fetch(data:...)`。
2. Tauri 默认拖放拦截与画布 HTML5 drop 路径不一致。主窗口及所有覆盖配置统一 `dragDropEnabled: false`，沿用画布现有导入路径。Windows 覆盖配置也检查，不能把 Mac 结果当 Windows 实测。
3. 本轮真实安装验收额外发现：冷启动后在项目列表重命名、再打开项目，画布被清空。工作区只预载 metadata，兼容 Map 中的 `elements: []` 是未加载占位，却被重命名/排序/移动写回完整存储；复制也会读到空内容。

## 修复

- Base64 原图本地解码，保留编码字节和 MIME；菜单解码前检查 64 MB 上限并返回明确错误，不放宽 CSP、不把原图替换成缩略图。
- 生成结果缓存和大参考图压缩使用相同本地解码方式，保留中止检查。
- 元数据写回前读取完整画板，保留 elements/viewport/theme，优先当前内存中尚未保存的内容；冷画板不因此长期驻留。重命名、排序、画板/文件夹移动及删除文件夹时移出画板共用该保护。复制先读取完整源画板。读失败拒绝写空占位。
- 没有新增持久化字段，没有数据迁移。历史已被清空的画板不能凭本修复自动复原；若任务结果仍存在，可从任务列表重新插入。

## 实现

- MCP 添加/编辑/删除/启停：所有受影响的旧工具和新增工具文件先解析、校验同名连接及准备内容，再检查原字节、写入文件，最后更新数据库。普通失败逆序补偿；发现外部修改则保留外部内容并返回需要人工核对的路径。未安装的旧工具仍不初始化。
- Claude 的 Windows 命令包装、Gemini 的字段/超时转换复用原转换；Codex 保留无关 TOML/注释，非法 TOML 拒绝覆盖；Hermes 保留非 MCP 区域及 OAuth/超时字段。导入比较按工具实际表示处理 OpenCode/Hermes HTTP/SSE 和空选填字段。
- Pi 的 pi_managed 仅保留为兼容状态，不再授予写入权。本机配置目录的隐藏 receipt 只保存规范路径和连接/启用状态摘要，不存凭证，不进入数据库、SQL 导出或 WebDAV。成功写入或显式导入才能认领；其他设备恢复数据库后需先导入本机条目。已有旧版 Pi 条目首次编辑同样需导入一次。
- 每个导入来源先校验后批量保存，来源内失败回滚。跨来源保留成功结果，失败结果在页面持续显示并支持重试；重复导入不重复新增。此语义不保证所有来源整体原子。
- 新增 Acceptance installers：gaizhao push 或手动触发，先前端回归，再 macOS ARM/x64、Windows x64、Linux x64 原生回归及安装包构建；仅上传 Actions 产物，附源码 SHA 和文件 SHA-256，不创建公开 Release，不更新自动更新清单。

## 实际边界

这是一套有冲突检测的同步失败补偿，不是跨文件/SQLite 的崩溃原子事务；断电/强制终止仍需检查文件后重试或从备份恢复，不声称具备持久事务日志。独立第三方写入不遵守应用锁，外部并发极短竞争窗口仍存在。

本轮不修改账户 API、不访问真实账户或付费服务。契约仍为 TA-AC-1.5-B4 / system-token-v1。下载页及其埋点在独立 API 仓库，本次客户端推送不代表网站已部署。develop 仅迁移版本记录；项目切换、原生匿名统计和底座全量整合见迁移记录，不能声称全部迁移完成。正式签名/公证按用户此前决定暂不做。

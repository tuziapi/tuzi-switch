# ADR-010：受控令牌预填与兔子线路创建草稿

日期：2026-10-19；状态：用户确认后本地实施；任务 B11；基线 `TA-AC-1.5-B4` / HTTP 契约 `system-token-v1` 不变。

用户要求修复供应商标题裁切、复制网站令牌回跳后的填入体验，以及单 Key 配置入口无法添加供应商的问题，并明确应打开对应工具的兔子线路表单、预填所选 Key。用户接受“有条件自动填入，仍手动连接”。本决策替代 ADR-008 B09 补充中“不自动读取剪贴板”的限制，其他 B4 权限/存储/事务规则不变。

## 令牌预填边界

- 点击助手“获取系统令牌”时，原生仅在无账户身份且未验证连接时创建内存许可，绑定 generation，使用单调时钟，5分钟有效。打开浏览器失败立即取消。
- 仅既有严格匹配的无参数 `tuziswitch://account/connect` 标记返回。深链不携带令牌、用户 ID、任意来源或返回地址。未经本机操作、重启/冷启动、过期或重复回跳不能授权读取。
- 当前连接表单输入为空、未连接、未验证时才请求 `account_take_token_prefill`。原生消费一次许可后读取剪贴板，无论读取失败或格式不符均不可重放。候选必须是网站实际生成格式：29～32位 Base62；模型 `sk-` Key、URL、空白、多行及其他格式不自动填入，旧格式仍支持手动粘贴。仅 debug-only `local-preview` 构建额外接受隔离测试站固定播种的两个明确合成令牌（preview / preview-admin），生产构建拒绝这些格式。
- 前端只在当前表单内存保留候选，以密码框遮罩显示；输入修订序号、组件存活、账户代次/状态用于丢弃迟到结果。用户输入、离开、开始连接、退出账户会取消许可。不给通用剪贴板读取接口，不定时轮询、不自动连接，不把候选放入 QueryCache、持久前端缓存、URL或日志。
- 页面明确告知回跳时尝试从剪贴板填入。剪贴板和深链都不能证明来源；格式校验不是账户认证。用户仍确认并点击连接，固定站点的原生身份验证和 OS 安全存储保持原流程。剪贴板不可用、候选不符或冷启动时手动粘贴。

替代方案：始终手动粘贴最简单但未满足用户要求；通过 URL 传令牌有泄露路径；剪贴板常驻监听扩大读取范围；自动连接可能意外切号。均未采用。不增加网站授权协议或服务端权限，不升级为 OAuth/SSO。

## 供应商草稿及保存

- 新建表单显示“兔子线路”和现有 tuzi 图标，使用对应工具已核实的主站端点与协议、所选 Key/兼容模型。Codex 复用原线路 TOML 生成器，但保留每张卡独立 `TUZI_SWITCH_*_CODEX_API_KEY`；不复用共享 `TUZI01` 凭证索引。受限模型不套用未经资格确认的预设模型名单。
- 分类初始化/提交不得把显式创建当成无预设空表单。原生接受 `third_party` 旧草稿及 `aggregator` 线路分类；固定端点/协议、模型 Key、来源证明、代次及服务端资格检查不变。OpenCode/OpenClaw/Hermes 预填唯一可编辑标识，并以提交标识保存，不丢弃用户输入的标识。
- 已存在来源继续按站点/用户/Key/工具/provider ID 定位，不通过名称猜测或覆盖旧卡。
- 点击添加生成脱敏预览，确认框使用独立滚动正文和固定按钮区；返回修改保留表单。保存中阻止重复提交和关闭，预览/保存失败明确反馈；保存失败需返回后重新生成预览。保留完整备份、并发检测和失败补偿。保存不代表模型测试。

## 兼容和回退

HTTP、网站令牌格式、深链、bundle/安全存储标识、数据库 schema 均不变。网站只调整引导文字，旧客户端仍可手动粘贴；新客户端可与旧网站的固定回跳兼容。两端可分别 revert B11 的对应提交；撤回自动填入后回到手动粘贴。不得删除安全记录、轮换共享令牌、恢复旧 A 或覆盖实际工具数据。测试层级与未验证项见 [B11验证](../token-prefill-provider-verification.md)。

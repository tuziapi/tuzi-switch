# ADR-028：隔离测试版显式连接本机客户端

日期：2026-11-24。任务 UC-OPENTU-CONNECT-1124。用户在核对隔离目录问题后明确批准「确认，开始实现吧」，授权将自有 OpenTu 连接器配置写入实际本机客户端。此项仅覆盖该入口，其他工具、账户及项目仍使用隔离目录。

实际机器存在无归属标记的旧 `tuzi-opentu` 项；用户随后单独批准「允许备份并替换旧连接」。执行时先做私有完整备份，再只移除核实过的旧条目，通过新版原生按钮安装。该机器的一次性迁移授权不改变产品的同名冲突保护，也不授权修改其他 MCP、模型或登录配置。

## 决策与兼容

保留旧命令默认行为；项目页和设置页显式请求 `connectLocal=true`。在执行前展示实际配置路径及工具权限说明，点击一次安装。不是自动跳过客户端授权或保证客户端热加载。

| 选择 | 优点 | 缺点与风险 | 决定 |
| --- | --- | --- | --- |
| 全局关闭测试隔离 | 所有工具立即访问真实目录 | 会影响其他工具和账户，不符合授权范围 | 不采用 |
| 只给 OpenTu 入口显式本机目标 | 保留其他隔离；现有配置事务可复用；配置一次后重启免重配 | 需显示目标、处理同名冲突，客户端可能需刷新 | 用户批准后实施 |
| 继续仅写隔离配置 | 无真实配置变更 | 当前客户端不能自动读到，无法满足真实连接目标 | 保留为旧命令默认和合成测试行为 |

本机路径按助手的 Codex 自定义目录、CODEX_HOME、真实用户目录下 .codex 解析；拒绝相对路径。CC_SWITCH_TEST_HOME 始终优先且保留隔离，合成测试不会写真实配置。全局 `get_home_dir()` 未改。

## 字段、状态与迁移

| 项目 | 定义与默认 |
| --- | --- |
| `connectLocal?: boolean` | 三个连接器 IPC 命令的可选参数；省略/false 保持旧行为。两个用户入口明确传 true |
| `expectedConfigPath?: string` | 安装/解除时传入页面已展示的路径，原生重算并比较；目标改变时拒绝。隔离版请求本机写入时必需；旧默认调用兼容 |
| `configPath: string` | 状态返回已解析配置路径，不含凭证 |
| `scope: local / isolated` | 状态返回实际目的地类型，合成测试明确显示隔离 |
| 独立运行记录 | 隔离版连接本机时使用应用数据根的 `opentu-local-connector/runtime.json` 与 enabled；原 `opentu-connector` 不迁移。正式版继续使用原目录 |
| `lastToolCallAt` | 保持原意：本次助手运行收到连接器转发的成功调用。不是目标客户端身份认证，不作为 ChatGPT 已验收证明 |

无服务端字段、SQL、账户授权或模型 Key 迁移。配置只增加 `mcp_servers.tuzi-opentu`，复用归属检查、文件锁、并发修改检测和原子替换。原生命令限定主窗口并串行化安装/解除。新安装发生同名冲突时清除本次新建运行记录，保留原配置；修复已有连接失败时保留原记录。重启同时刷新已启用的两种运行记录；解除只处理所选目标和对应运行记录，不删除画布或另一种连接。

## 验证与回退

原生用合成目录验证显式选址、测试环境强隔离、覆盖目录优先、拒绝相对路径、目标变化拒绝、自有项幂等安装/解除、其他配置保留、独立记录保留和同名冲突。前端验证目标展示、安装/解除参数和成功状态分离；复验原画布桥接。

实际安装包须验证按钮写入本机目标、其他配置不变、重启连接器读取和解除后的配置恢复。目标 ChatGPT/Codex 窗口有电脑控制限制；需要用户在客户端完成刷新/确认及发起工具调用。不能用脚本替代该验收，也不新增公网 Tunnel。

回退前在新版对所选目标解除连接，再恢复旧包。直接退回旧测试包会保留真实配置却停止刷新新目录，因此不能省略解除步骤。发布状态及实机证据见 [验收记录](../2026-11-24-opentu-connection-acceptance.md)。

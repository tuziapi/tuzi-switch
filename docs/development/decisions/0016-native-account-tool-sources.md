# ADR-016 新工具账户来源与恢复

日期：2026-10-27。状态：本地实施，待真实工具验收。

账户 Key 配置至 Grok Build、Pi、MiniMax Code 时，复用账户资格校验与独立工具文件适配器，不将三者加入既有七工具 AppType。原生层固定协议及端点、重新验证模型资格和一次性 reveal 证明，并在 revision 校验后备份、原子写入。

来源关联放在既有单步备份中，并记录配置哈希；恢复或普通修改时维护来源。备份存放原始配置，可能包含模型 Key，须使用私有文件权限，来源元数据本身不存密钥。外部更改来源配置时保守地取消来源标识。单步备份不能提供多版本历史。

另一方案是扩展旧供应商数据库和 AppType；这会扩大既有七工具契约和迁移范围，因此本阶段沿用独立适配器。单独查询新工具来源可隔离文件损坏，代价是额外 IPC 及对失败状态的处理。回退时需保留用户工具配置与备份，不自动清理文件或账户数据。

# ADR-011：账户本地配置文件与隐藏Codex环境变量

日期：2026-10-19；任务B13；状态：用户明确授权，本地实施。基线TA-AC-1.5-B4 / 契约system-token-v1。

## 批准来源与范围

用户先要求避开账户钥匙串弹窗，后明确纠正为“保存为一个配置文件，而不是修改授权流程”，并确认环境变量表单一起修改。本决定覆盖ADR-008/technical-design/AGENTS中账户系统令牌仅OS安全存储的旧要求；不扩大到工具OAuth等其他凭证，不授权远程发布。

## 账户文件

原生独立本地JSON明文保存，位于系统用户本地数据目录的com.tuziswitch.desktop/account，预览使用com.tuziswitch.desktop.preview/account。origin/client的SHA256作为文件名，正式与测试及不同账户服务互不混用。记录版本仍为v2，校验站点/client/version，前端普通IPC不返回令牌。Unix目录0700/文件0600，Windows依赖用户本地目录的继承ACL；临时文件同步后原子替换，64KiB上限，拒绝目标文件/直接父目录符号链接。

该文件不是加密保险箱；同一系统用户权限的程序和管理员可能读取。当前选择由用户明确要求本地文件作出。应用数据库/SQL导出、WebDAV的数据库与Skills白名单、供应商备份均不包含此独立目录；不承诺操作系统级备份排除。不存在钥匙串失败时的明文回退分支，因为唯一后端已改为文件。

旧钥匙串记录不读取、不自动迁移、不删除，避免迁移本身再次触发授权。首次使用需重新粘贴一次系统令牌；之后从文件恢复并向服务端验证身份。本地断开写入空v2记录，清内存而不轮换网站令牌。失败维持原有不伪报成功及代次屏障。

未选择调整授权/静默钥匙串读取，用户明确否定该方向；不实施自动导出钥匙串、修改ACL或去除系统授权保护，也不修改签名发布流程。

## Codex表单

只移除Codex的独立环境变量输入与说明；Claude认证字段、Gemini.env编辑及其他工具机制保留。原始配置中的env_key继续存在。新建或旧配置确实缺失时，从现有供应商和受管理环境键实时避重；合法编号沿用TUZI/CODING格式，通用名称使用后缀。编辑时以原配置TOML为准、旧env.envKey为兼容，前后端均保留原变量名。旧hook不再凭空补OPENAI_API_KEY，避免错误绑定其他供应商密钥。已有非法引用不能静默改名，给出重新导入/新建的修复路径；原生保存失败不再吞错并提交空凭证。

## 兼容与回退

API无代码/HTTP/DTO/schema变化；API HEAD按验证报告记录。客户端使用现有指定B分支本地实施；用户已有未提交改动保留。回退使用独立本地提交的revert；不清数据、删除旧钥匙串或轮换共享令牌。回退到旧版本可能重新读取旧钥匙串连接，需要事先核对旧账户状态，不能承诺新版本断开会清除旧钥匙串条目。

验证、实际包状态与Windows/Linux限制分别见B13验证报告。

# ADR-018：创作共用模型适配流程，分开获取凭证

日期：2026-11-04（Asia/Shanghai）。任务：UC-TRANSPORT-01。状态：用户已选择，本地实施。

## 问题与批准

同一模型 Key 使用手动配置可以进入创作适配器的请求流程，但账户关联还会经过前端 action 映射、原生 action 映射和模型目录端点校验。原映射只包含部分协议，因此 Kling、MiniMax、Suno 等已有适配器会被客户端拒绝，模型目录缺少标签也会导致不必要的拒绝。

用户明确选择“统一模型适配流程，分开凭证获取”。此决定替代 UC-P02 中新账户调用必须经过固定 action 清单和端点标签资格检查的规则；保留账户归属、凭证隔离、目标地址与取消边界。仅授权本地实施和验证，没有新增推送、PR、发布或真实付费调用授权。

## 方案比较与决定

| 方案 | 优点 | 缺点、维护与风险 |
| --- | --- | --- |
| 按协议逐项扩展账户 action | 单次修复较小 | 两套适配继续分离，新增协议、参数或轮询方式时易遗漏 |
| 共用适配与 HTTP，独立获取凭证（采用） | 请求体、上传、查询和响应无需账户特例 | 首次需验证协议覆盖、凭证隔离、错误响应及取消；原生仍须约束地址 |

创作模块原有模型适配器继续选择 URL、方法、请求头和请求体。宿主两种来源调用相同的 `prepareCreativeRequest`，JSON、multipart、二进制均序列化为实际 HTTP 字节，保留上传文件名及 MIME；原生共用 `creative_http::prepare` 与 `send_response`。

- 手动来源保留既有配置凭证。
- 账户来源只携带不可变绑定引用及账户代次；原生读取当前本人 Key 详情、校验启用/到期/额度并取得模型 Key，在原生内存注入 Bearer。系统令牌只访问原账户接口，不进入模型请求、前端、创作配置或导出。
- 账户生成和轮询不再先抓 `/v1/models`，不再按 `model` 字段、模型名或目录端点标签重写/拒绝请求。权限最终由模型服务使用实际 Key 执行；省略标签不等于拒绝，列出模型也不等于保证生成成功。
- 显式获取模型直接转发该 Key 的 `/v1/models` 响应，与手动获取一致。工具配置自己的资格校验和一次性 proof 保持原逻辑。
- 账户仍限制固定绑定 origin 与模型服务命名空间。共享 JSON 策略包含 `/v1/`、`/v1beta/`、`/v2/`、`/kling/`、`/suno/`、`/mj/`、`/flux/`、`/minimax/` 和图片找回 `/log/get-request`；不是模型/动作清单。未知顶层命名空间及账户管理路径不自动获准；以后新增协议只需已有适配器和受管命名空间匹配。
- 前端剔除凭证占位 header/query；原生再次移除 renderer 凭证与账户身份头、拒绝凭证 query、跨域、路径绕过和重定向。业务查询参数、原请求 ID、协议版本头和字节不改写。
- 共用 HTTP 状态、脱敏错误体、SSE/二进制交付及 64 MiB 限制。账户 HTTP 错误现在是与手动一致的 Response，适配器可按状态处理；不暴露可能回显凭证的上游错误正文。
- 账户代次在发送前、接收响应和分块期间检查；沿用账户 pending/cancel。断开取消正在获取凭证或等待生成的请求，不自动切 Key、切站或重发生成。

## 字段与兼容

新增原生命令 `creative_account_http_request`，请求字段：`generation:u64`、`bindingId:string`、`requestId:UUID`、`url:string`、`method:string`、`headers:Record<string,string>`、`body:base64|null`。未知字段拒绝；请求 ID、方法、头与体大小复用手动校验。响应与取消协议不新增字段。

没有新增持久化字段、数据库迁移、服务端 API 或契约版本变化；`system-token-v1` 和绑定文件 schema 1 保持。旧 `creative_account_request` action 命令作为旧 renderer 兼容入口保留，不再增加新协议；新 renderer 只使用共用 HTTP 入口。预览夹具同步识别新命令。

必须随完整原生客户端一起交付，不能把新 renderer 单独投放到没有新命令的旧原生包。此处不进行版本或发布流水线改动。

## 验证及回退

原生使用本机随机端口的合成账户和模型服务，对照两种来源的实际 HTTP 方法、路径、查询、请求头、上传字节及响应分块；另验证禁用、跨代次、错误归属、重定向、错误脱敏和取消。前端覆盖实际序列化、multipart 文件名和认证占位剔除。

完整命令、结果与限制见 [实施记录](../2026-11-04-creative-unified-transport.md)。本轮不代表真实供应商生成或三平台安装包验收。回退本地提交即可恢复旧入口，不删除绑定、项目、Key 或账户文件。

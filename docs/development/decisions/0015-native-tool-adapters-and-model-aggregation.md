# ADR-015：新增工具原生文件适配与按模型聚合

日期：2026-10-27。状态：本地实现，尚未发布和完成真实工具验收。

## 背景与决定

用户确认先补视觉，再进入 Grok Build、Pi、MiniMax Code 和聚合能力阶段。参考用户指定的 `/Users/sdy09/Documents/ChatGPT/cc switch` 源码，其中 Grok 使用 TOML、Pi 使用 models.json、MiniMax 使用 YAML；聚合按模型指向指定供应商，不等同于故障转移。该参考目录有源码但 Git HEAD 不可解析，因此不把它当作可核验的上游提交版本。

新增工具采用独立、穷举的 NativeTool 枚举和原生文件适配命令，不把尚未接入七工具全部功能的新工具加入旧 AppType。旧 AppType 的 OAuth、MCP、Skills、账户配置到工具、导入导出和各自写入语义保持边界。新页面直接管理原生供应商档案，使用原生字段 JSON 编辑器；不伪造已有全部扩展能力。

- Grok：`~/.grok/config.toml` 的 model 表和 models.default；选择档案不改官方登录。
- Pi：`~/.pi/agent/models.json` 的 providers；支持 PI_CODING_AGENT_DIR。登录、settings.json 和当前模型由 Pi 管理。
- MiniMax Code：`~/.minimax/config.yaml` 的 custom_provider；支持 MINIMAX_DATA_DIR / MAVIS_DATA_DIR。原生账户供应商禁止编辑，当前默认模型的删除/禁用受保护，登录和选模留给原工具。
- local-preview 构建的新适配器忽略上述环境覆盖，使用独立预览 home。

原生配置写入前校验 SHA-256 修订，进程互斥和文件锁目录串行；使用0600临时文件、sync和原子替换，新建父目录0700。备份记录精确目标路径、原始字节和写后摘要，恢复只允许当前文件仍匹配最后一次助手修改。未知字段保留；Grok 保留无关 TOML 字段/注释，Pi/YAML 重新序列化但不承诺保留注释排版。前端只保存内存草稿，离开新工具页不持久缓存凭证。

聚合仅对 Claude Code / Codex 的第三方 API 供应商开放。名单、默认供应商和每条模型的窗口均显式保存；无前缀请求走默认供应商，其余使用稳定、可逆的供应商ID编码生成保留前缀。未知、删除或停用的前缀请求报错，不回落到其他供应商。

聚合请求复用现有协议、凭证和流处理适配器；绕过路由队列、熔断记录及当前供应商切换，不产生隐藏的故障转移。Claude 使用网关模型发现，Codex 使用原有模型模板生成独立模型目录。模型窗口是用户配置值，不自动证明模型真实能力。

模式转换使用独立读写锁；新增/编辑/删除/启用供应商以及手动切换模式受保护。先校验、再复用现有按工具接管，最后写模型目录覆盖层；覆盖层写前持久化恢复日志。恢复同时验证目标路径和文件摘要，有外部修改时保留备份并拒绝覆盖。退出聚合返回普通路由，用户随后可选直连；应用退出和崩溃恢复接入既有原生恢复路径。正常退出后名单保留，但不自动重新启用聚合。

## 替代方案与影响

| 方案                                          | 取舍                                                                                      |
| --------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 扩展全部旧 AppType 分支并导入整套上游模式引擎 | 涉及大量旧配置、数据库和七工具特性，可能误接不支持的功能；本阶段不整批移植。              |
| 只增加三个导航按钮和聚合标签                  | 无真实配置写入和分发，不能满足本阶段目标。                                                |
| 独立原生适配器与复用路由的聚合覆盖层          | 保留旧行为，实施可独立验证；代价是新工具扩展页、官方 OAuth 聚合及聚合高级设置需继续开发。 |

本版不包含新增工具的 MCP/Skills/会话适配、官方 OAuth 聚合、聚合子代理/自动审批模型设置、模型自动发现和能力自动补全；这些不是已完成能力。不得将本地合成验证当作真实 CLI / macOS 桌面 / 三平台验收。回退先退出聚合并恢复新增工具备份，再使用 git revert 回退提交，保留业务数据与用户配置。

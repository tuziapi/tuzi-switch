# ADR-027：本地压缩与专用 AI 视频处理分离

日期：2026-11-23。状态：用户已选择「本地压缩＋专用 AI 服务」；本地压缩 Mac ARM 实机验收通过，专用服务尚未选定/配置。任务 ECOM-ACCEPT-1123，先验收再发布。

## 决策

压缩使用随安装包提供的独立离线 FFmpeg 进程，不使用模型额度、服务器上传或账户 Key。背景移除、4K 超分、修复与去水印仍须专用服务，不把重新生成视频当作这些处理的实现。

| 引擎方式 | 优点 | 代价/风险 | 选择 |
| --- | --- | --- | --- |
| 客户自行安装 FFmpeg | 安装包小 | 版本、路径、编码器不确定，支持成本高 | 不采用 |
| 固定源码构建的随包引擎 | 离线、可取消、跨平台参数一致；无额外安装步骤 | 增加包体与原生构建维护，须随附源码/许可并实测每个平台 | 采用 |
| 浏览器实时录制 | 不增加原生二进制 | 后台节流、音轨和编码支持依赖 WebView，不能稳定保证完整转码 | 不采用 |

## 原生与打包

- `scripts/prepare-media-runtime.mjs` 固定 FFmpeg 9.1、x264 提交及 pkgconf 源码 URL/摘要，自行编译，只打开文件/管道协议与指定编解码器。产物位于 Cargo 忽略目录，不提交二进制。引擎、原始源码归档、构建配方、许可和来源清单随包分发。
- 主窗口通过原始二进制 IPC 传入至多 128 MiB，固定三个画质档、三个尺寸档、音频开关；无路径、命令、任意 FFmpeg 参数。原生不查 PATH，不用系统 FFmpeg 作为运行时回退。
- 同时最多一个压缩进程，最多两线程，超时两小时；独立临时目录自动清理，原文件不改写。取消、退出时终止实际子进程。输出上限 128 MiB；达到限制丢弃结果，避免把截断视频当成功。
- 输出 MP4/H.264/AAC；保持画面比例、处理样本宽高比、尺寸按长短边限制，不放大小尺寸；音频可保留或移除。高于 4K 的素材会降至 4K 上限；有损转码不能保证每段素材都更小，界面据实际字节数报告变化。
- 原生五平台矩阵需要各目标本机编译工具链；Windows 增加 MSYS2 UCRT64。拒绝未支持的跨架构打包，防止混入宿主架构引擎。尚未运行远端矩阵，不将本机 ARM 成功泛化为五平台通过。

## 新增字段与兼容

| 项目 | 定义/默认/旧版本行为 |
| --- | --- |
| `CreativeAccountBridge.compressVideo?` | 可选宿主桥；旧宿主缺少时禁用压缩并说明；独立于账户登录 |
| 请求头 | UUID `x-compression-id`；quality=balanced/small/high；resolution=original/1080p/720p；audio=keep/remove；原生逐项拒绝非法值 |
| 进度 | `creative-compression-progress`，`id`＋已处理秒数；前端只接受当前任务，未保存前不显示 100% |
| IndexedDB | 新建独立 `tuzi-video-compression` / `records`，不修改原图片/视频任务库 |
| 记录 v1 | id/createdAt/name/originalBytes/duration/options/status，成功附 video Blob，失败附 error；无 URL、凭证、模型或账户字段 |
| options | quality 默认 balanced，resolution 默认 original，keepAudio 默认 true；每条记录保存执行时快照 |
| status | running/complete/interrupted；重启后 running 显示 interrupted，重新选原片执行，不使用远端任务/计费提示 |
| 失败和回退 | 存储失败保留内存结果供导出，不伪报已保存；旧版本忽略独立数据库，不删除记录；没有自动恢复未完成压缩 |

本地压缩记录尚未并入 WebDAV 备份；导出视频为用户可移交文件。无服务端接口、SQL 迁移或账户授权改变。专用服务的配置、凭证来源和数据上传目的地须在选型后另行补齐，不能借此复用账户系统令牌。

## 验证

当前原生引擎测试 2 项（包括实际打包引擎转码与执行前取消）通过；创作 141 项及宿主媒体 11 项通过，类型检查通过。最终 Mac ARM 安装包实际压缩两段素材，音轨保留/移除、运行中取消、导出和冷启动播放均通过；文件完整解码、流时长和尺寸核对通过。证据、包摘要、跨平台及发布限制见 [发布门禁](../2026-11-23-ecommerce-release-gates.md)。尚未推送/发布。

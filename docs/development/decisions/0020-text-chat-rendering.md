# ADR-020：文本长会话按可见区域渲染

日期：2026-11-08。UC-TEXT-03，用户要求本地桌面聊天避免卡顿；属于已批准文本聊天范围内的性能实现，不改变模型、存储或产品入口。

## 决定及依据

在 `c9b7039c` 的同机合成基线中，300 个会话、当前会话 800 条消息产生 35,710 个聊天 DOM 节点；流式回复的最大帧间隔为 333.4ms。IndexedDB put 的同步耗时最大仅约 0.3ms，因此优先减少渲染工作，不延长保存间隔。

| 实现 | 优势与适用范围 | 成本、风险与控制 |
| --- | --- | --- |
| 全量消息 DOM + content-visibility | 短会话简单，原生跨消息查找和选区完整 | 长会话仍保留全部 React/DOM、Markdown 节点；继续用于不超过 60 条的会话 |
| 复用已有虚拟列表依赖 | 长会话只挂载视口附近消息，保留完整本地数据和上下文 | 动态高度及跟随滚动需回归；视口外文本不能直接通过浏览器查找/跨越选区获取 |
| 仅扩大流式/保存间隔 | 改动少 | 不能解决大量 DOM；增加显示延迟或未保存窗口，本次不采用 |

超过 60 条启用已有 `@tanstack/react-virtual`，按稳定消息 ID 测量高度，视口前后各预留 4 条。使用立即定位及 ResizeObserver 跟随已测高度，避免 scrollToIndex 延迟重试覆盖用户上翻。保留逐条复制、完整上下文及完整本地会话，不删减历史。

会话侧栏行采用 memo，收起侧栏不挂载列表；收起聊天后暂停聊天组件运行时订阅并卸载其 DOM，后台请求与持久化独立继续。保存成功且无错误状态变化时不发送多余 UI 通知；失败与恢复仍通知。新增对话等待持久化期间锁定输入，避免快速输入落在上一会话。

## 兼容、验证与回退

无新依赖、持久化字段、数据库版本或接口变化。仅新增可选组件参数 `visible`，默认 true；现有调用不变。40ms 显示节流、700ms 保存节流、首次发送前保存与最终落盘均保留。

浏览器性能采样和行为回归分别记录，覆盖上翻不抢位置、末尾定位、动态换行、收起后台完成、完整历史重载及快速新建。测量不是全部硬件/原生 WebView/供应商表现的保证。单条极长 Markdown、极大历史总量及屏幕阅读器遍历的成本仍有边界；具体结果见 [实施记录](../2026-11-08-opentu-text-chat.md)。本地 revert 可恢复全量渲染，不需要迁移或删除数据。

# ADR-025：OpenTu 的 Codex 本地连接器

- 日期：2026-11-22
- 任务：UC-OPENTU-CONNECTOR-1122
- 状态：用户选择并授权本地实施；尚未发布
- 基线：v1.6.3，`fedb2205`；分支 `codex/opentu-codex-connector`

## 问题与选择

现有 Streamable HTTP 连接要求用户填写 URL 和 Authorization，且兔子助手每次启动随机更换端口和令牌。实测中用户把令牌粘贴进了 Codex 的“Bearer 令牌环境变量”栏。用户选择“一键安装本地连接器”，要求配置一次、重启免重配。

| 选择 | 优点 | 代价/限制 |
| --- | --- | --- |
| 手动 HTTP | 无额外进程，可供其他支持 HTTP 的客户端使用 | 填写容易出错，每次重启需更新 |
| 自动填写 HTTP | 安装操作简单 | 客户端仍持有过期端口/令牌，仍需重载配置 |
| 内置 stdio 连接器（采用） | Codex 配置只含稳定命令和本地运行记录路径，每个请求自动发现新服务 | 维护 stdio 转发及本地运行记录；首次可能需客户端刷新 |
| 固定端口、永久令牌 | 配置稳定 | 端口冲突及长期令牌轮换问题；不采用 |

## 实现

- `src-tauri/opentu-connector` 是无 GUI 的 Rust 库，宿主已有二进制通过 `--opentu-mcp-stdio <absolute-runtime-path>` 进入连接器模式。入口早于 Tauri 和单实例插件，不拉起第二个窗口，不依赖 Node、Python、npx 或额外下载。
- Mac/Windows 使用安装中的程序路径；Linux AppImage 使用 `APPIMAGE`，避免写入短暂的挂载路径。移动/删除应用后需要点击“修复 Codex 连接”。
- 每次请求重新读取用户本地应用数据目录 `opentu-connector/runtime.json`，保持已启动的 stdio 进程可切换至新端口和新令牌。兔子助手未运行时返回可操作的错误；不会自动启动应用或自动重复付费生成请求。
- 运行记录仅包含本地 MCP endpoint 和本次启动的随机 capability，不包含模型 Key 或兔子账户系统令牌。它不进入数据库、工具配置、WebDAV、项目文件或前端状态。只有点击安装后才启用发布，重启继续发布新值。
- Unix 目录 0700、文件 0600，原子替换；读端检查权限、普通文件、inode 和大小。Windows 继承当前用户应用数据目录的权限，Windows ACL 与安装包实测仍列为发布门禁。
- endpoint 限制 `http://127.0.0.1:<port>/mcp`，禁止凭证 URL、query、fragment；不使用代理、不跟随重定向。stdout 只输出 JSON-RPC，错误不包含令牌、HTTP 请求体或配置内容。
- 转发按输入顺序执行；不实现取消已经提交的创作任务，保持原有异步任务查询方式。工具超时 130 秒，HTTP 总期限 125 秒，上游期限 120 秒。输入/输出最多 4 MiB。

## Codex 配置与恢复

- 使用独立 `mcp_servers.tuzi-opentu`；通过命令、参数和专用 env 标记识别自有项。写入保留其他 MCP、模型、注释和账户设置。
- 仅同一连接器的配置可重复安装/修复/解除。同名用户配置、无效 TOML、非普通文件和并发连接器写入失败时保留原文件。
- 配置采用本地锁、保存前重新比较及原子替换。锁只能协调本连接器，不能承诺与不遵循此锁的外部编辑器完全事务互斥。
- 尊重兔子助手的 Codex 自定义目录，随后检查 `CODEX_HOME`，否则使用默认目录。隔离预览和测试只写隔离目录。
- 解除仅删除自有配置与连接器运行记录；现有手动 HTTP 项不自动删除，因为不能凭名称认定归属。已有手动 OpenTu 项时提示用户停用旧项。
- 正常安装之后无需更新端口/令牌；Codex 是否即时发现新增 MCP 取决于客户端。界面提示刷新 MCP 或重新打开会话，不自动重启客户端。

## 状态含义

“配置已写入”不是“Codex 调用成功”。状态只在本次应用运行中收到连接器转发的成功 `tools/call` 后更新，表示连接器调用成功，不能证明所有模型生成、跨平台或特定客户端均已验收。手动 HTTP 与本地健康检查保持独立。

## 范围与回退

此次只支持本机 Codex 的配置安装；ChatGPT 云端连接、Tunnel、自动启动/重启客户端不属于此次范围。保留手动 HTTP 入口。

回退前使用“解除连接”，再恢复旧包；代码回退用独立 commit 的 revert。已安装的旧版 1.6.3 不具有新按钮，不能将源码完成视为安装/发布完成。验收见 `../2026-11-22-opentu-codex-connector.md`。

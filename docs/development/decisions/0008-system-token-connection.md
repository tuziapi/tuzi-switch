# ADR-008：账户系统令牌替代桌面 OAuth

日期：2026-10-18；状态：已采纳（用户明确产品授权，普通实现选择依据源码）；基线 `TA-AC-1.5-B4`，契约 `system-token-v1`。本轮只本地开发/验证/提交/集成，不授权远程与生产。

## 背景、证据和目标

A 已有本地账户页面、工具事务和 `/api/desktop` OAuth 实现，但未对外发布。用户明确选择 B：网站复制自己的账户系统令牌，粘贴后原生验证、安全保存并调用原站接口，保留全部业务和隐藏页面。最新网站在 `dded57caedc376c4399f778ebb2147748bc24743`，不能退回旧 A 网站。

源码 `model/user.go` 的 `AccessToken` 为 `users.access_token` 唯一系统管理凭证；ValidateAccessTokenContext 按数据库匹配，无独立 TTL；GenerateAccessToken 替换值，GetAccessToken 读取现值。中间件还检查账户状态/角色及后续 New-Api-User。系统令牌不是模型 Key，不提供 OAuth scope/刷新/单设备撤销；密码变更是否使其失效不可凭 A 推断。

## 决策及替代范围

采用单一 B 流程，不保留 A/B 选择，不实施未来 SSO。新增窄 GET `/api/user/self/bootstrap` 只用系统令牌（不依赖 Cookie），首次确认用户 ID；后续原接口继续 matching ID。复用原路由，必要扩展限于原子 PATCH、本人完整汇总及可选认证兼容；不重建新前缀 facade。

| 历史决定 | B4 替代部分 | 继续有效部分 |
|---|---|---|
| ADR-001/002 | 桌面公共客户端、scope、code/AT/RT 寿命、OAuth 表/迁移/撤销/独立路由 | 产品业务、五资料字段、七工具、凭证不混用 |
| ADR-003/004 | 刷新 journal/签名授权 context、RT 退避、桌面安装 required/撤销清理 | 原生系统存储选型、固定 origin/禁重定向、失败不明文、故障如实记录 |
| ADR-005 | 传输中的 OAuth 身份及 `/api/desktop` | 来源证明、完整写集备份/恢复、独立供应商凭证、工具事务全部保留 |
| ADR-006 | A 本地预览的账户 OAuth 配对 | 隔离预览、合成数据、不接生产和证据分层 |
| ADR-007 | `/api/desktop` 服务端 Phase 1 scope/路由闸门 | 客户端 Phase 1 Key+四概要、隐藏页面/配置入口及不加载隐藏请求 |

B 不具备桌面 scope，不能保留 ADR-007 的服务端限制承诺或用静态客户端 Header 模拟权限。旧 ADR/Word/审计/验证原样留存，当前执行以 B4 为准。

## 权限代价及替代方案

选择 B 复用现有账户系统令牌和业务接口，减少独立授权体系与第二套业务路由。代价是令牌共享、无每设备最小 scope/独立 TTL/单连接撤销；管理员令牌拥有实际管理权限。原生白名单只约束助手请求，令牌泄露后不能约束其他调用者。网站与客户端须准确说明账户级权限，安全存储和脱敏不可削弱。

继续 A 能保留细粒度 scope/连接撤销，但与用户本轮选择冲突；将 `/api/desktop` 改名仍保留第二套接口不满足原站复用；依赖 Cookie/用户手抄 ID/全局取消 ID 校验均拒绝。客户端 GET 合并 PUT 无法防并发覆盖，采用服务端锁内部分更新。未来 SSO 仅考虑版本化存储/来源隔离，不实施。

## 兼容、迁移及回退

网站用固定非敏感来源/锚点引导、可信 return_to、登录后定位；读取/复制不生成，轮换需独立明确确认共享失效。令牌不进 URL，无自动回传。无引导参数的个人设置保留原行为。

客户端 v1 A 记录要求重连，B v2 不互认；不删除业务数据，不移除工具 OAuth/导入深链，不把系统令牌配置成模型 Key。连接先持久化空 v2 记录，再验证并保存令牌/身份；断开以空 v2 tombstone 覆盖而非删除安全条目，失败不得报告本地凭证已清除。只清本地，不轮换共享凭证。网络错误保留可重试，轮换/禁用与无效分别处理。

API B 基于最新网站，不集成 A 的独立表迁移/required/撤销钩子/清理器，原网站 OAuth 等不变；现存本地 A 表/标记只核查保留，不 DROP、不自动恢复旧授权。精确本地 DB 事实由集成负责人记录，不把“未发布”当删除依据。

先 API/网站兼容扩展后客户端是后续获批上线顺序；回退只用核验配对版本，旧 A 不能自动重新活跃。先回 API 时客户端显示不兼容不自动走 A。应用回退保留数据/schema，系统令牌失效须用户主动网站轮换。实际生产权限/数据库/三平台/容量仍待验证，当前无发布。

## 验证

对应 PRD AC-01～18、B01～B07 与迁移矩阵；网站登录/已登录/读取复制/生成轮换/失败恢复/开放重定向，原生存储/恢复/代次/受控请求，普通/管理员本人、Key/profile 并发 PATCH、完整汇总、隐藏页面/七工具和旧站回归分别记录。Mock/单端/真实 HTTP/原生/真实 UI 不能相互替代。

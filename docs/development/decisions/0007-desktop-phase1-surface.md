# ADR-007：兔子助手 Phase 1 开放面

日期：2026-10-15；状态：已采纳；基线 `TA-AC-1.5-B3`，契约 `desktop-v1.1`。

## 决策

兔子助手首期固定进入 API 密钥工作区，并在密钥列表上方显示总览四项摘要：账户余额、今日消耗、今日消费调用、今日 token。调用明细、模型、模型状态、资料和网站操作暂不在客户端开放。

API 服务端在独立 `/api/desktop` 路由增加 Phase 1 闸门，能力响应区分底层 `native` 和当前 `release`；未开放路由即使持有合法桌面令牌也返回 `desktop_feature_unavailable`。不使用 API 站全局 `sidebar_modules`，避免改变普通网站用户页面。

## 取舍与回退

客户端隐藏菜单和不加载隐藏页面只负责体验，服务端闸门负责实际安全边界。保留现有 OAuth scope 和授权 wire，减少本轮迁移与旧客户端兼容风险；后续扩大开放面时，先调整服务端 release profile，再恢复客户端入口和对应验证。回退可单独关闭 desktop business 或撤销本地代码，不影响 API 站旧路由。

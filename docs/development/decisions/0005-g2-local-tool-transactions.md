# ADR-005：G2 原生业务传输与账户来源工具保存

日期：2026-10-14；基线 TA-AC-1.5-B3，desktop-v1.1 / desktop-v1。状态：已实施并通过G2本地验证，证据以 g2-verification 为准。产品范围及接口契约不变。

## 问题与决定

G2页面需要经原生层读取桌面业务，账户OAuth不得传至WebView或工具。采用固定正式origin、method/path白名单的原生业务IPC，不接受调用方header、origin或任意网页URL。测试loopback仅cfg(test)。连接代次在请求前后校验；401协调一次刷新，403不刷新，429保留限制；只读有界重试，写结果未知不自动重试。取消仅取消业务future，不能破坏刷新journal。

T15沿用既有供应商创建表单与七工具适配器，不另建工具配置实现。账户来源保存先经过兼容选择和显式揭示，原生仅在内存保存揭示所得模型Key的SHA-256及用户、token、连接代次和短期有效期；保存必须匹配该证明，成功消耗。明文不持久化到来源表。同步写事务持有账户来源守卫，退出或切换账户不能在保存期间改变来源。闭包不能再次调用账户服务，避免重入死锁。

保存前原生重新读取当前用户的Key和表单实际选择的模型，检查状态、到期、额度、模型限制、可见分组（含虚拟default解析）与协议端点。Claude Desktop读取实际代理路由的上游模型，其他工具读取各自配置模型。远端读取完成后再持有来源证明守卫写本机，账户代次变化会拒绝保存；远端资格在读取之后发生变化无法与本机事务原子化，不宣称跨系统事务。

工具事务预览与保存绑定完整表单hash，预览过期或文件/数据库变化要求重做。第一次环境、数据库、配置文件或自动启用写入前，持久备份整个适配器写入集合及供应商相关数据库状态。配置写入journal拒绝超出集合的写入，对原有普通工具写入保持行为。保存与启用分别报告，不自动调用付费模型。失败尽量补偿，外部并发变更时停止覆盖并保留可核对备份；恢复前比较完整文件与相关数据库签名。

Codex账户保存不在事务末尾调度异步图片兼容收敛，防止后台任务写入未备份的技能、owner或代理配置；现有图片兼容状态保持。普通工具流程保留其原有调度。恢复数据库时只恢复本次新provider、其endpoint/来源和Claude Desktop gateway设置，不用完整快照覆盖无关settings、proxy或用量历史。损坏/缺失after记录仍显示本机人工核对入口，拒绝自动覆盖。

来源表只记站点、用户、token、工具、provider关联，不猜测旧配置归属；SQL导出/WebDAV排除该本机关联。模型Key备份按本机访问权限保护，备份不能包含兔子账户OAuth（其仅在系统安全存储）。

## 替代方案与兼容

- 任意URL代理会扩大账户AT可达范围，拒绝采用。
- 仅靠前端sk-格式或来源标签不能证明账户归属，改用原生揭示证明。
- 重写七工具适配器会改变既有独立凭证索引与自动启用行为，故以受控完整写集包裹现有适配器。
- 单纯数据库备份不能恢复工具文件、环境与接管配置，不能满足AC-09。

无新增远程API、OAuth scope或生产数据库迁移。新IPC和本机关联表属于客户端增量；普通手工供应商流程保持现有语义。并发签名是防止盲目恢复的门禁，不宣称跨进程文件系统原子事务。

## 回退与限制

本地代码回退使用git revert，先回退依赖该IPC的页面与T15入口，再回退原生实现；G1安全存储、撤销/清理与R1/R2修复必须保留。工具配置回退经本机备份入口且先做并发检查，不用Git回退代替真实配置恢复。失败/冲突时保留备份，不能强制覆盖用户新修改。

macOS临时配置、SQLite及合成Key测试不证明Windows注册表、Linux实际安装、跨平台安装包或生产MySQL/多实例验证完成；这些属于G3门槛。实现、固定SHA非作者审查与逐工具证据见g2-verification；本地G2通过不代表G3或发布完成。

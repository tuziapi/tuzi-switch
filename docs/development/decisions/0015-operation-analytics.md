# ADR-015：受限操作事件与结果统计

日期：2026-10-26；状态：按用户确认的第一期方案实施；任务 ANALYTICS-02。

在已有 Umami 基础脚本之上，使用统一白名单出口和业务提交点调用，不新增 SDK 或服务端接口。导航基于 React 视图状态去重；写操作在原生/API 成功或失败返回后记录结果，不使用按钮点击代替成功，不采集后台轮询。结果无法确认时保留 unknown，导入部分成功保留 partial。

替代方案为 DOM 自动点击采集或全局 IPC/HTTP 拦截：前者无法确认操作结果、可能捕获输入内容；后者会混入后台请求并扩大数据接触面，因此不采用。事件仅传固定枚举与构建版本；不建立用户标识，不传业务数据与原始错误。事件字典、环境和计数口径见 [操作统计说明](../analytics-events.md)。

上报 best-effort，不持久化、不重试、不中断业务。代价是脚本未加载、离线、关闭窗口时可能丢报，统计不能用作计费或精确审计。现有账户/工具配置、原生行为和基础 PV 统计兼容；独立 revert 本任务提交即可回退自定义事件，无数据迁移。

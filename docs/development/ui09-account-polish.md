# UI-09 兔子账户圆角视觉适配

日期：2026-10-27。用户同意沿用 Agents 的简洁圆润风格，授权进入账户视觉阶段。基于 `gaizhao` / `18d9a107`；仅客户端展示与隔离预览，无 API、原生命令、账户凭证或业务字段变化，无 push/PR/发布。

## 实施范围

- 账户连接信息改为圆角卡片，连接状态用文字和小圆点并列，保留断开说明、检查连接、离线/错误状态与重试。
- 余额、今日消耗、调用及 Tokens 使用同一组圆角概要卡和小图标；金额计算、数据来源与已记录消费说明不变。
- 密钥筛选区、币种切换、创建按钮及状态标记统一胶囊样式；表格浅边框和圆角容器，窄窗口保留内部横向滚动。依据账户容器宽度调整概要和筛选排列；修正换行连接卡在预览 flex 容器内被压缩的问题。
- 未连接页、密钥创建/详情/编辑和配置到工具弹窗统一圆角、输入框与内边距。工具选择增加真实 aria-pressed 状态，已选工具用蓝色细边与淡底表达。高级选项、取消/确认及模型菜单保留。
- 从账户创建供应商时用 `data-account-prefill` 限定表单样式，延续圆角卡片和底部按钮；普通供应商表单不扩大改动。
- 新样式放在 account-polish.css，仅限公开账户页和账户弹窗。无新持久字段，不改变 Phase 1 隐藏页面、系统令牌、七工具兼容、保存事务、独立凭证和恢复逻辑。本轮不接入三个新工具的账户一键配置。

# SITE-ACCEPT-1125：真实登录验收与入口修复

用户要求实际验收当前 Mac 预览。基线 `71196c4d`，本地检查及问题修复，无 push/PR/发布。用户亲自在应用内输入凭证，测试不读取、复制或记录凭证，不发送聊天或执行支付。

## 发现并修复

旧版直连站已登录后，完整退出再进入又显示登录页。公开 `https://web.tu-zi.com/login` 源码的 DOMContentLoaded 主动清理登录身份；固定每次启动访问此页导致登录保持失败。原有合成 Cookie 检查没有覆盖这个真实网站行为，因此此前不能放行真实登录验收。

修复保留首次指定登录页，平台首页加载完成后仅记住允许列表中的公共根地址。允许列表核对公开 `/platforms/config`，不保存令牌跳转地址、查询串、fragment 或会话内容。新文件字段、默认回落、兼容及回退详见 ADR-029。网站认证和退出登录行为不改。
